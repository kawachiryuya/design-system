## 設計思想：Primitives / Composites と依存ルール

戦略文書 `design-system-strategy.md` で定義した 2 層構成です。Atomic Design の「依存方向の制約」を継承しつつ、分類の曖昧さを排除しています。

- **Primitives**：単一のHTML要素をラップした最小部品。他のコンポーネントを import しない。
- **Composites**：Primitives を組み合わせた複合コンポーネント。Primitives のみ import 可。
- **プロダクト層**：すべてを import 可。本リポジトリ外（別プロダクトリポ）で管理。

```
Primitives    他のコンポーネントを import しない
    ↑
Composites    Primitives のみ import 可
    ↑
プロダクト層   すべてを import 可（別リポジトリ）
```

プロダクト固有のコンポーネント（プロダクト固有のドメイン依存 UI）は本リポジトリには含めず、プロダクト側リポで本パッケージを依存として使う構成です。

## デザイントークン

すべてのコンポーネントは `tokens/` ディレクトリの JSON ファイルを参照しています。
Tailwind CSS の設定にも統合済みです。

- **Color** — Primitive (hue palette × 10 shades) + Semantic (surface / on / border / state)
- **Typography** — Primitive (font-size / weight / line-height / family) + Semantic (heading / body / label / caption)
- **Spacing** — 8px ベースの数値スケール (component 内部余白で使う)
- **Layout** — page-level frame token (container / section / grid) — multi-product で大外レイアウトを統一管理
- **Shadows** — `none / sm / md / lg` のエレベーション
- **Radius** — `none / sm / md / lg / full` の角丸
- **Animation** — duration (動きの長さ) + easing (速度カーブ)
- **Breakpoints** — `sm / md / lg / xl / 2xl` の 5 段 (Tailwind 標準)
- **Z-Index** — `dropdown / sticky / overlay / modal / popover / toast / tooltip` の 7 layer (semantic-only)
- **Opacity** — `disabled / muted / spinner-track / spinner-spin` (semantic-only)
- **Focus Ring** — `ring-focus` (width / offset) (semantic-only、色は別 token)

→ サイドバーの **Tokens** カテゴリで視覚的に確認できます。詳細は [Tokens/Overview](?path=/docs/tokens-overview--docs) 参照。

## Product 側で使う際の setup

別 product で本パッケージを依存として使うときの手順。**v4.0.0 以降、消費側に Tailwind は不要**です（コンポーネント CSS をプリコンパイル同梱）。

**1. 2 つの CSS を import**（アプリのエントリで一度だけ。`src/globals.css` や `app/layout.tsx` 等）

```css
/* トークンの CSS 変数（テーマ override の起点） */
@import '@kawachiryuya/design-system/tokens/variables.css';
/* コンポーネントのプリコンパイル済みスタイル（使用 utility のみ・リセット非同梱） */
@import '@kawachiryuya/design-system/styles.css';
```

`variables.css` に `--color-surface-primary` 等の全 token CSS 変数、`styles.css` にコンポーネントが使う utility が入っている。**両方**を import する（片方だけでは壊れる）。順序は variables → styles。

**2. コンポーネントを import して使う**

```tsx
import { Button, Card, Modal } from '@kawachiryuya/design-system';

<Button variant="primary">保存</Button>
```

> 旧来必要だった Tailwind の **preset 継承**・`content` スキャンは不要になりました。`tailwind.config.js` から本パッケージの preset 行と `node_modules/@kawachiryuya/...` への content glob を削除してください（移行手順は CHANGELOG `4.0.0` 参照）。

### 自分のマークアップでも DS の utility class を書きたい場合（任意 / Tailwind）

同梱の `styles.css` は **DS コンポーネントが実際に使う utility のみ** を含みます。自社アプリの JSX で `bg-surface-primary` / `px-container` / `grid-base` などの DS utility を**自由に**書きたい場合は、従来どおり Tailwind の preset を継承してください（この経路では `styles.css` は import 不要。`tailwindcss` は自社の devDependency として持つ）:

```js
// tailwind.config.js
module.exports = {
  presets: [require('@kawachiryuya/design-system/tokens/preset')],
  content: ['./src/**/*.{tsx,ts}'],
};
```

```css
/* globals.css */
@import '@kawachiryuya/design-system/tokens/variables.css';
@tailwind base;
@tailwind utilities;
```

```tsx
// preset 経路なら DS utility を自由に組める
<div className="px-container py-container max-w-container mx-auto">
  <section className="space-y-section-md">
    <button className="bg-surface-primary text-onSurface-inverse">Primary</button>
  </section>
</div>
```

### Token 値を product 全体で override

`src/globals.css` の `:root` で CSS 変数を上書き。**build 不要、cascade で全 callsite に即時反映**。

```css
:root {
  /* brand を violet に切り替え (color chain 全体が連動) */
  --color-teal-700: #5B4C99;

  /* 大外 max-width を 1440px に */
  --layout-container-max-width-default: 1440px;

  /* section の density を全体的に詰める */
  --layout-section-gap-md: 32px;
}
```

詳細は各 token の Guideline ([Tokens/Color/Semantic](?path=/docs/tokens-color-semantic--guideline) / [Tokens/Layout](?path=/docs/tokens-layout--guideline) 等) 参照。

## アクセシビリティへの取り組み

WCAG 2.1 の **POUR 原則** (Perceivable / Operable / Understandable / Robust) に従い、**Level AA を最低目標** として実装しています。

- **ARIA属性**：role・aria-label・aria-invalid・aria-modal などを適切に付与
- **キーボード操作**：Tab / Shift+Tab / Enter / Space / Escape / 矢印キー対応。`tabindex` は 0 または -1 のみ（DOM 順序 = フォーカス順序）
- **フォーカス管理**：2px outline + コントラスト 3:1+ のフォーカスインジケータ、Modal は focus trap（ネイティブ `<dialog>` で標準対応）、動的コンテンツ追加/削除時は論理的な次要素へフォーカス移動
- **色コントラスト**：通常テキスト 4.5:1 以上、大テキスト・UI 要素 3:1 以上を遵守
- **タッチ操作**：最小ターゲット 44×44px、隣接間隔 8px+、ホバー依存禁止
- **a11y アドオン**：各 Story の「Accessibility」タブで axe-core 自動検証結果を表示

実装規約の詳細は `AGENTS.md §8 アクセシビリティ前提`、設計思想は `design-system-strategy.md > 設計原則 > アクセシビリティ基本方針` を参照。
