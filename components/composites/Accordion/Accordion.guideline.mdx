## 概要

折りたたみ式のリスト UI。FAQ・補足説明・設定セクション等、**最初は全てを見せず、必要な項目だけ開いて読ませたい** 場面に使う。`type="single"` は 1 つだけ開く (FAQ 等)、`type="multiple"` は複数同時に開ける (設定セクション等)。controlled / uncontrolled の両方をサポートし、URL クエリ等との同期も可能。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **同階層の切替表示** (タブ的) | `<Tabs>` | 横並び固定の表示切替に最適化 |
| **複雑な階層構造ナビ** | (Sidebar / Tree pattern) | Accordion は単純な開閉、ネスト前提ではない |
| **常に全文表示が重要** | (Section 並べ + h2/h3) | 隠す必要がないなら平叙の段落で |
| **「もっと見る」ボタン** (1 つの長文の続き) | (Read more pattern) | Accordion は複数項目のリスト用 |

## アクセシビリティ

- **`<button aria-expanded aria-controls>`**: 各 trigger は button 要素。開閉状態を `aria-expanded` で SR に伝達
- **`role="region" aria-labelledby`**: 展開されたコンテンツは region として、trigger が見出し相当 (`aria-labelledby` で関連付け)
- **キーボード操作**: `Tab` で trigger 間移動、`Enter` / `Space` で開閉発火 (button 標準)
- **`aria-disabled` + `disabled`**: 無効項目は両方付与。クリック不可で SR にも「無効」が伝わる
- **focus ring**: 現実装は color-based、将来 `ring-focus` 統一予定
- **タッチターゲット**: trigger は p-4 (16px padding) で十分な大きさ。WCAG 2.5.5 達成
