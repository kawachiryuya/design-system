## 概要

ページ上に **永続的に表示するインラインの通知メッセージ**。状況 (success / error / warning / info / neutral) を色とアイコンで伝え、必要なら閉じるボタンで dismiss できる。**一時的な通知 (操作直後にスッと出てスッと消える)** には `<Toast>` を使う。

### 別コンポーネントの方が適切な場面

「これは Alert じゃないかも?」と迷ったときは下の表で目的に合うコンポーネントを探す:

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **操作直後の一時的フィードバック** (「保存しました」等、数秒で消える) | `<Toast>` | 自動消失・通知スタック対応、画面を占有しない |
| **モーダルな確認ダイアログ** ("削除します。よろしいですか?") | `<Modal>` | フォーカストラップ + 操作の確定/取消ボタン付き |
| **ステータスを 1 単語で示す** ("完了" バッジ等) | `<Badge>` | コンパクトなラベル、文章ではない |
| **空状態のメッセージ** (検索結果ゼロ件等) | `<EmptyState>` | 大きめの説明 + アクションへの誘導に最適化 |

## アクセシビリティ

- **`role="alert"`**: コンテナに自動付与され、SR が即座に内容を読み上げる (live region)。`error` variant は特にこの挙動が重要
- **アイコンの装飾性**: アイコンはテキストの補強であり、SR には読まれないよう `Icon` 内部で `aria-hidden` 相当の処理。テキストで意味を伝えることが前提 (WCAG 1.4.1)
- **コントラスト**: variant ごとの背景 (`surface.X-muted`) と文字 (`onSurface.X`) の組み合わせで WCAG AA を満たす設計
- **閉じるボタン**:
  - `aria-label="閉じる"` を必ず付与 (icon-only の SR 文言)
  - フォーカスリングは `focus-visible:ring-focus` + `ring-current` で variant 色に追従
  - `Tab` でフォーカス、`Enter` / `Space` で発火 (button 標準挙動)
- **キーボード操作**: `Tab` で閉じるボタンと内部 Link / Button にフォーカスが移動。Alert 自体は focusable ではない
