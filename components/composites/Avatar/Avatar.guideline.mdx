## 概要

ユーザーや組織を表す **小さなアイコン UI**。`src` (画像) → `name` (イニシャル) → プレースホルダーアイコン の **3 段フォールバック** を持つ。`role="img"` + `aria-label` (name + status) を自動付与し、SR にもユーザー情報が伝わる。チャット・コメント・ユーザーカード・グループ表示等で使う。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **状態を 1 単語で表示** ("オンライン" 等のテキスト) | `<Badge>` | Avatar は人/組織の識別、状態テキストは Badge の用途 |
| **大きな画像 (アイキャッチ等)** | `<Image>` | Avatar は小さなアイコン、大きな画像は Image |
| **アイコン (人ではない)** | `<Icon>` | Avatar は人/組織を表現、抽象アイコンは Icon |

## アクセシビリティ

- **`role="img"` + `aria-label`**: 自動付与、SR に「ユーザー名 (status)」を読み上げる
- **`<img alt>`**: 画像表示時の alt は `alt` prop または `name` を fallback として使用
- **status dot は装飾**: `aria-hidden="true"` 自動付与、外側コンテナの `aria-label` に状態名を統合 (二重読み防止)
- **イニシャルは装飾**: `aria-hidden="true"`、SR には label の name が伝わる
- **コントラスト**: イニシャル文字 (text-onSurface-inverse) と name ハッシュベース背景色で AA 達成
- **decorative 用途**: 純粋な装飾 (e.g. UI illustration の人物画像) なら `alt=""` で SR から外す
