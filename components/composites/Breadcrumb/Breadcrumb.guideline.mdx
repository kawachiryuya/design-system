## 概要

階層構造の現在位置を示すナビゲーション。最後の項目は **現在ページ** として `aria-current="page"` 自動付与、それ以前は親階層へのリンクとして機能する。サイト構造が深い (3 段以上) ページや、複数経路から辿れるコンテンツで「今ここ」を示すのに使う。2 段の浅い階層では省略可。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **サイト全体のメイン navigation** | (Header / Sidebar 等の Pattern 層) | Breadcrumb は補助的な「現在位置」表示で、主たる navigation ではない |
| **タブ切替** (同階層内の表示切替) | `<Tabs>` | パンくずは縦階層、タブは横並び |
| **戻る/進む** (履歴ベース) | (ブラウザ標準) | 履歴を辿るのは breadcrumb の役割ではない |
| **多段ドリルダウン** (E コマースカテゴリ折り畳み) | `<Accordion>` / category tree | 動的に開閉が必要なら別 component |

## アクセシビリティ

- **`<nav aria-label>`**: 外側 `<nav>` に `aria-label="パンくずリスト"` (デフォルト)。SR でランドマークとして識別される
- **`<ol>` 構造**: 順序付きリストで階層を表現。SR は「1/4 ホーム、2/4 ブログ…」のように読み上げる
- **`aria-current="page"`**: 最後の項目 (現在ページ) に自動付与。SR で「現在ページ」と読まれる
- **separator は装飾**: `aria-hidden="true"` 相当の処理 (Icon / span)。SR には読まれず項目だけが伝わる
- **link focus ring**: `focus-visible:ring-focus` でキーボード focus を明示
- **truncate**: `max-w-[200px]` でラベルが長くても折り返さず省略。tooltip 検討余地あり (将来)
