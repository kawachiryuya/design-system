## 概要

見出し / コンテンツ / フッターを持つ **汎用コンテナ**。compound component (`Card.Header` / `Card.Body` / `Card.Footer`) で構造的に組み立てる。3 つの variant (`elevated` / `outlined` / `filled`) で強調レベルを切替、`href` 指定で link、`clickable` + `onClick` で button として動作 (キーボード操作 + role 自動付与)。リスト項目 / 統計表示 / 設定セクション等の枠組みに広く使う。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **モーダルダイアログ** | `<Modal>` | 画面全体を遮断、focus trap、Esc キー閉じ |
| **画面内のお知らせ** | `<Alert>` | 状態色 + アイコン、SR に `role="alert"` |
| **データなしの代替表示** | `<EmptyState>` | icon + 説明 + アクションへの誘導に最適化 |
| **タブの中身** | `<Tabs>` の panel として | Tabs の compound として組み込み |

## アクセシビリティ

- **clickable / onClick**: `role="button"` 自動付与、`tabindex=0`、Enter / Space で発火
- **href**: `<a>` タグでレンダリング、ブラウザ標準の link 挙動
- **focus ring**: clickable / href 時に `focus-visible:ring-focus`
- **Header / Body / Footer の意味付け**: 各 div は role を持たない (article 等で wrap するのは利用側の責任)
- **重要: card 内に link / button がある場合**: card 自身を clickable にしない (nested interactive 違反)。card 内の link / button のみ interactive にする
- **hover 表現**: bg-state-hover の neutral overlay、AA contrast 保持
