## 概要

**フォーム入力用の複数選択 / 単独 ON/OFF チェック**。`<input type="checkbox">` ベースで、フォーム送信に乗せたい設定 / 利用規約同意 / 興味カテゴリ等に使う。複数まとめるときは `<CheckboxGroup>` で `<fieldset>` + `<legend>` でラップし、共通 errorMessage / helpText を持てる。即時反映設定 (ダークモード等) には `<Switch>` を、排他選択には `<Radio>` を検討。indeterminate 状態は親「全て選択」で一部のみ選択中を表現する。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **即時反映の ON/OFF** (設定) | `<Switch>` | 切替後すぐ反映、フォーム送信不要 |
| **複数選択肢から 1 つ排他** | `<Radio>` | 排他制御、Checkbox は複数選択用 |
| **多数の選択肢から 1 つ** (6 個以上) | `<Select>` | 一覧性ではなく省スペース |
| **トグルボタン的な選択** (テキスト + active 状態) | `<ToggleButton>` / `<FilterChip>` | 視覚的なボタン UI |

**会員登録フォーム（RadioGroup + CheckboxGroup + 同意チェック）** — `max-w-container-narrow` + `space-y-section-sm` のフォーム枠に、性別 (Radio inline) / 興味カテゴリ (CheckboxGroup) / 利用規約同意 (required CheckboxGroup) を積む。送信時に未同意なら Group の `error` を Context で全子に伝播させ、赤枠 + errorMessage を出す（動的 validation の実挙動は Storybook の Playground 系で確認）。

<form className="w-full px-container py-container max-w-container-narrow mx-auto bg-surface border border-border-subtle rounded-md">
  <div className="space-y-section-sm">
    <h3 className="text-heading-sm text-onSurface m-0">会員登録</h3>
    <RadioGroup legend="性別" inline>

      <Radio name="ex-gender" value="other" label="その他" />
    </RadioGroup>
    <CheckboxGroup legend="興味のあるカテゴリ" helpText="複数選択できます">
      <Checkbox label="テクノロジー" />
      <Checkbox label="デザイン" />
      <Checkbox label="ビジネス" />
    </CheckboxGroup>

## アクセシビリティ

- **`<input type="checkbox">`**: ネイティブの role / aria 挙動を継承
- **`<fieldset>` + `<legend>` (CheckboxGroup)**: グループとして SR に伝達
- **`aria-invalid` + `aria-describedby`**: error / helpText / errorMessage と関連付け自動
- **`aria-checked="mixed"`** (indeterminate 時): browser が自動付与
- **キーボード操作**: `Tab` で focus、`Space` でトグル (browser 標準)
- **focus ring**: `focus-visible:ring-focus` で keyboard focus 時のみリング
- **タッチターゲット**: 20×20px (1 サイズ運用)。input 自体は 20px だが `<Label htmlFor>` でラベルもクリック領域、ラベル含めて WCAG 2.5.5 (44×44px) を達成
- **ラベルクリック**: `<Label htmlFor>` でラベルクリックでもトグル
