## 概要

**フォーム入力用の複数選択 / 単独 ON/OFF チェック**。`<input type="checkbox">` ベースで、フォーム送信に乗せたい設定 / 利用規約同意 / 興味カテゴリ等に使う。複数まとめるときは `<CheckboxGroup>` で `<fieldset>` + `<legend>` でラップし、共通 errorMessage / helpText を持てる。即時反映設定 (ダークモード等) には `<Switch>` を、排他選択には `<Radio>` を検討。indeterminate 状態は親「全て選択」で一部のみ選択中を表現する。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **即時反映の ON/OFF** (設定) | `<Switch>` | 切替後すぐ反映、フォーム送信不要 |
| **複数選択肢から 1 つ排他** | `<Radio>` | 排他制御、Checkbox は複数選択用 |
| **多数の選択肢から 1 つ** (6 個以上) | `<Select>` | 一覧性ではなく省スペース |
| **トグルボタン的な選択** (テキスト + active 状態) | `<ToggleButton>` / `<FilterChip>` | 視覚的なボタン UI |

## アクセシビリティ

- **`<input type="checkbox">`**: ネイティブの role / aria 挙動を継承
- **`<fieldset>` + `<legend>` (CheckboxGroup)**: グループとして SR に伝達
- **`aria-invalid` + `aria-describedby`**: error / helpText / errorMessage と関連付け自動
- **`aria-checked="mixed"`** (indeterminate 時): browser が自動付与
- **キーボード操作**: `Tab` で focus、`Space` でトグル (browser 標準)
- **focus ring**: `focus-visible:ring-focus` で keyboard focus 時のみリング
- **タッチターゲット**: sm / md / lg。md 以上で WCAG 2.5.5 達成
- **ラベルクリック**: `<Label htmlFor>` でラベルクリックでもトグル
