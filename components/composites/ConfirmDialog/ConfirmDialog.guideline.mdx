## 概要

役割「**確認**」の部品。操作を実行する前に、本当に実行してよいかを確かめる (戻せない削除・取り消し・送信など)。見出し (問いの形)・短い説明・取り消しと確定の 2 つのボタンだけで、ボタンは部品が持つ。どの幅でも画面の中央のカードで、**外 (背景) を押しても閉じない**。入力があるなら `FormDialog`、押した要素についての補足で外を押すと閉じてよいなら `Popover`、元に戻せる操作は確かめずに実行して `Toast` で「元に戻す」を出す。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **ひとまとまりの入力をして確定する** (絞り込み・座席の変更) | `<FormDialog>` | 中身が `<form>`。入力欄で Enter を押すと確定。狭い幅は画面いっぱい |
| **押した要素についての補足・軽い操作** | `<Popover>` | 外を押すと閉じる軽い重なり。狭い幅は下から |
| **選択肢・操作から 1 つ選ぶ** | `<Menu>` | 選んだら閉じる。戻せない操作は、選んだ後に ConfirmDialog で確かめる |
| **元に戻せる操作の結果を伝える** | `<Toast>` | 確かめずに実行し、「元に戻す」を出す方が流れを止めない |
| **処理の結果 (成功・失敗) を伝える** | `<Toast>` / `<Alert>` | 結果のために dialog を開くと、閉じる手間が増え、失敗の内容を見ながら直せない |

## アクセシビリティ

- **土台はネイティブの `<dialog>` の `showModal()`**: 背景は操作できず、フォーカスは中に閉じ込められる。開いている間は背景 (html と body) もスクロールしない
- **`role="alertdialog"`**: 読み上げの名前は見出し (`title`、`aria-labelledby`)、説明は `children` (`aria-describedby`)。説明を省くと `aria-describedby` は付かない
- **外 (背景) を押しても閉じない**。閉じ方は `Esc`・× (閉じるボタン)・取り消しボタンで、どれも取り消しとして `onClose` を呼ぶ。確定ボタンは `onConfirm` を呼ぶだけで、閉じるのは親 (`open` を false にする)
- **開いた直後のフォーカス**: 確定ボタン。`destructive` のときは取り消しボタン (Enter の連打で戻せない操作が実行されない)。× には置かない
- **閉じた後のフォーカス**: 開く前にフォーカスがあった要素へ戻す (ブラウザの働き)。開く前の要素が閉じた後に残らないとき (Menu の項目から開いたときなど) は、`returnFocusRef` に入口を渡す。戻すのは、閉じたときにフォーカスが dialog の中にあったときだけ
- **フォーカスの輪**: 指・マウスで開いた (直前の操作が指・マウス) ときは、中でキーが押されるまで輪を出さない (フォーカスは移す)。指・マウスで閉じて戻したフォーカスも同じ。キーボード・読み上げの「実行」で開いた・閉じたとき、まだ何も操作していないときは出す
- **ブラウザが閉じたとき**: 親が閉じる要求に応えないまま `Esc` を続けると、ブラウザは dialog を閉じる (止められない)。このときも `onClose` を呼び、`open` が true のままなら出し直す
- **閉じるボタン (×)** と 2 つのボタンは 48px の高さ。ボタンは右寄せで、取り消し → 確定の順。収まらないときは折り返す
