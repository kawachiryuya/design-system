## 概要

トリガーから開く単一階層のアクションメニュー (WAI-ARIA APG の Menu Button パターン)。「実行できる操作」を集約する用途に使う。`<Popover>` と同じ overlay 基盤 (native `popover` 属性 + `@floating-ui/dom`) を共有し、その上に `menu` / `menuitem` の roving tabindex・矢印キー・typeahead を載せている。

**「選択して実行」専用**。フォームの値入力やフィルタ条件の選択 (選んだ状態が残る) は `<Select>` / `<SegmentedControl>` を使う。ナビゲーションのタブ切替は `<Tabs>`。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべきコンポーネント | 理由 |
|---|---|---|
| **値・条件を選んで保持** (フィルタ / 設定値) | `<Select>` / `<SegmentedControl>` | 選択状態が残るコントロール。menu は実行のみ |
| **ナビゲーションのタブ切替** | `<Tabs>` | 同階層コンテンツの表示切替 |
| **補助情報・自由なレイアウト** | `<Popover>` | menu 構造でない任意コンテンツ |
| **背景遮断して確認させる** | `<Modal>` | focus trap + 背景遮断が要る重要操作 |

## アクセシビリティ

- **WAI-ARIA APG Menu Button 準拠**: トリガー `aria-haspopup="menu"` / `aria-expanded` / `aria-controls`、パネル `role="menu"`、各項目 `role="menuitem"`
- **キーボード操作**: 開くと最初の有効項目へフォーカス。`↑` `↓` で項目移動 (disabled をスキップ)、`Home` / `End` で先頭 / 末尾、`Enter` / `Space` で実行、`Esc` / `Tab` で閉じて trigger にフォーカスを戻す
- **typeahead**: 項目名の先頭文字を入力すると一致項目へジャンプ (`label` が文字列でない場合は `textValue` を指定)
- **roving tabindex**: アクティブな項目のみ `tabIndex=0`。メニュー全体で Tab 1 ストップ
- **light-dismiss**: native `popover="auto"` により外側クリック / Esc で閉じる
- **非モーダル**: focus trap は張らない (メニューの標準的な振る舞い)。`prefers-reduced-motion` は preset でグローバル対応済
