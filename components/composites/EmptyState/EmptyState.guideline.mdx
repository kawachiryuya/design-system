## 概要

データなし・検索結果ゼロ・初回利用時等の **「何もない状態」を埋めるプレースホルダー UI**。アイコン + タイトル + 説明 + 行動を促す Button (action / secondaryAction) で構成され、ユーザーに「次に何をすればいいか」を示す。ローディング中の表示には使わない (それは `<Spinner>` / `<Skeleton>`)。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **データ取得中** (Loading) | `<Spinner>` / `<Skeleton>` | EmptyState は「何もない確定状態」、Loading は「まだ確定していない」 |
| **エラーで一時的に表示** (再試行可能) | EmptyState (icon=ErrorIcon) | 実は EmptyState のユースケースに含まれる。永続的エラーは Alert + EmptyState の併用も可 |
| **一行のメッセージ** ("選択中: 0 件" 等) | (テキスト + Typography) | 大きな空間が要らない情報 |
| **モーダルな確認 / 通知** | `<Modal>` / `<Toast>` | EmptyState は画面の一部 (リストや section) を埋める用途 |

## アクセシビリティ

- **icon は装飾**: `aria-hidden="true"` 自動付与、SR には読まれない。意味はテキストで伝える
- **タイトル + 説明文の階層**: タイトルは `font-semibold`、説明は `text-onSurface-muted` で視覚的階層 (見出しタグは使わない、用途上適切でないため)
- **アクションの focus**: 内部 `<Button>` が標準の `ring-focus` を持つため、`Tab` で focus 可
- **色だけに頼らない**: エラー状態の icon は色 + 形 (×印など) で意味を伝える
