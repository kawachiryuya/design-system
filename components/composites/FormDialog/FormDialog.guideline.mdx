## 概要

役割「**作業**」の部品。ひとまとまりの入力をして、確定するか取り消す (絞り込み・座席の変更・名前の変更など)。中身は部品が `<form>` で包み、取り消しと確定のフッターも部品が持つ。**画面の幅 640px 未満は画面いっぱい、以上は中央の大きいカード**で、**外 (背景) を押しても閉じない**。入力の無い長い中身 (読ませるだけ) は入れない (押した要素の補足は `Popover`、長い文は別のページ)。入力の無い確かめは `ConfirmDialog`、入力が多い・何段にも分かれる作業は別のページにする。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **入力の無い確かめ** (戻せない操作の前) | `<ConfirmDialog>` | 見出し・短い説明・2 つのボタンだけ。どの幅でも中央のカード |
| **押した要素についての補足・軽い操作** | `<Popover>` | 外を押すと閉じる。狭い幅は下から |
| **選択肢から 1 つ選ぶだけ** (並び順など) | `<Menu>` | 選んだら閉じる。確定ボタンが要らない |
| **入力が多い・何段にも分かれる・長い文を読ませる** | 別のページ | 画面を覆う重なりの中で長い作業をさせない。URL で戻れる |

## アクセシビリティ

- **土台はネイティブの `<dialog>` の `showModal()`**: 背景は操作できず、`Tab` は dialog の中を巡る (最後の要素から `Tab` を押すと、ブラウザのアドレスバーなどへ 1 度出てから中へ戻る。ネイティブの dialog の働き)。開いている間は背景 (html と body) もスクロールしない
- **読み上げの名前は見出し** (`title`、`aria-labelledby`)。`role` は `dialog`
- **中身は本物の `<form>`**: 入力欄で `Enter` を押すと確定する (`onSubmit`)。ページの移動 (既定の送信) は部品が止める。`required` などブラウザの入力チェックは効き、通らないと `onSubmit` は呼ばれない。確定ボタンが押せない (`submitDisabled`)・読み込み中 (`submitLoading`) の間は、Enter でも確定しない
- **外 (背景) を押しても閉じない**。閉じ方は `Esc`・× (閉じるボタン)・取り消しボタンで、どれも取り消しとして `onClose` を呼ぶ。確定しても部品は閉じない (親が `open` を false にする)
- **開いた直後のフォーカス**: 本体の中の最初の押せるもの (多くは最初の入力欄)。無ければ dialog そのもの。× には置かない
- **閉じた後のフォーカス**: 開く前にフォーカスがあった要素へ戻す (ブラウザの働き)。開く前の要素が閉じた後に残らないとき (Menu の項目から開いたときなど) は、`returnFocusRef` に入口を渡す。戻すのは、閉じたときにフォーカスが dialog の中か、どこにも無い (body) ときだけ
- **フォーカスの輪**: 指・マウスで開いた (直前の操作が指・マウス) ときは、中でキーが押されるまで輪を出さない (フォーカスは移す)。指・マウスで閉じて戻したフォーカスも同じ。キーボード・読み上げの「実行」で開いた・閉じたとき、まだ何も操作していないときは出す
- **中に Menu・Popover を置いたとき**: それらの `Esc`・外を押す操作で閉じるのは、それらだけ。それらの中の入力欄で `Enter` を押しても、この dialog は確定しない
- **ブラウザが閉じたとき**: 親が閉じる要求に応えないまま `Esc` を続けると、ブラウザは dialog を閉じる (止められない)。このときも `onClose` を呼び、`open` が true のままなら出し直す
- **狭い幅 (640px 未満)**: 画面いっぱい。見出しの行とフッターは動かず、本体だけスクロールする。フッターの下に端末の余白 (safe-area) を足す
- **閉じるボタン (×)** と 2 つのボタンは 48px の高さ。ボタンは右寄せで、取り消し → 確定の順。収まらないときは折り返す
