## 概要

役割「選ぶ」の部品。押した要素に属する選択肢・操作から 1 つを選び、選んだら閉じる (WAI-ARIA APG の Menu Button パターン)。**狭い幅 (画面の幅 640px 未満) では画面の下から、広い幅では押した要素の近くに出る。どちらで出すかは部品が決め、使う側は選ばない**。どちらも外を押すと閉じる。

使い方は 2 つ:

- **1 つ選ぶ** — 並び順・種別など、今の値から 1 つを選び直す。項目に `selected` を持たせると、選択中の行の右にチェックが出て、読み上げにも選択中が伝わる。開くと選択中の項目にフォーカスが来る
- **操作の一覧** — 変更・複製・削除など、押すとすぐ実行する操作を集める。`selected` は持たせない (チェックの列も出ない)

フォームの欄で値を選んで送信するもの (住所の都道府県など) は `<Select>`、選択肢を常に見せて切り替えるもの (2〜4 個) は `<SegmentedControl>`、戻せない操作の確認は `<Modal>` を使う。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべきコンポーネント | 理由 |
|---|---|---|
| **フォームの欄で値を選んで送る** | `<Select>` | フォームの値として持ち、送信される。Menu は選んだらすぐ反映・実行する |
| **2〜4 個の選択肢を常に見せて切り替える** | `<SegmentedControl>` | 開かずに今の値と他の選択肢が見える |
| **補足の情報・自由なレイアウト** | `<Popover>` | 選択肢・操作の並びでない内容 |
| **戻せない操作の確認・まとまった入力** | `<Modal>` | 外を押しても閉じない。Menu は外を押すと閉じる軽いものだけ |
| **ナビゲーションのタブ切替** | `<Tabs>` | 同じ階層の内容の切り替え |

## アクセシビリティ

- **WAI-ARIA APG Menu Button 準拠**: 入口に `aria-haspopup="menu"` / `aria-expanded` / `aria-controls` (出ている形のメニューを指す)、メニューは `role="menu"`、項目は `role="menuitem"` (1 つ選ぶメニューは `role="menuitemradio"` + `aria-checked`)
- **キーボード (どちらの幅でも同じ)**: 開くと選択中の項目 (無ければ最初の有効な項目) にフォーカス。`↑` `↓` で移動 (無効な項目は飛ばす)、`Home` / `End` で先頭 / 末尾、項目名の先頭文字で移動、`Enter` / `Space` で選ぶ、`Esc` で閉じる、`Tab` は閉じて入口に戻す。閉じたら入口にフォーカスが戻る
- **狭い幅の形**: 下から出る面 (`<dialog>` の `showModal()`) の中にメニューを置く。面の名前は見出し (`title`) で、メニューには名前を付けない (同じ名前を二重に読ませない)。開いている間は背景を操作できず、背景はスクロールしない。面の閉じるボタンには `Tab` では行かない (`Tab` はメニューを閉じる) ので、閉じるのは `Esc`・項目を選ぶ・外を押す・閉じるボタンを押す。上端の帯を下に引いて閉じる動きは指の操作の近道で、同じことは閉じるボタンと `Esc` でできる
- **選択中の印**: チェックのアイコンは読み上げから外し、選択中は `aria-checked` で伝える
- **タッチ**: 狭い幅では行の高さ 48px 以上。開いてから 300ms は押しても反応しない (入口の二度押しが、上がってくる面の項目に当たらないように)
- **フォーカスの輪**: 項目のフォーカスは輪だけ (内側 2px、`focus-ring-inset`、キーボードのときだけ)。指・マウスで開いたときは、開いた直後に項目へフォーカスは移すが、キーを押すまで輪を出さない (キーを押したらそこから出す。キーボードで開いたときは、はじめから出す)。塗りはホバーだけで、ホバーと見分けが付く (形の使い分けは AGENTS.md §3-2「フォーカスの規則」)
- **roving tabindex**: アクティブな項目だけ `tabIndex=0`。メニュー全体で Tab 1 ストップ
- **広い幅の形**: native `popover="auto"` で外を押す / `Esc` で閉じる。フォーカスは閉じ込めない (メニューの標準的な振る舞い)。`prefers-reduced-motion` では下から出る動きを付けない
