## 概要

数値専用の controlled 入力。`+` / `−` ボタンで値を増減する **stepper 型 UI**。チケット枚数 / 人数 / 数量入力など、**範囲が決まっていて少数 (〜数十) の整数を選ばせる用途** に向く。任意の数値テキスト入力には `<Input type="number">` を使う。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **任意の数値テキスト入力** (年齢・金額等) | `<Input type="number">` | キーボードで直接打鍵、桁数が多い数値 |
| **小数や単位付き** (¥ / kg 等) | `<Input>` (textbox) | stepper では小数や単位を扱いづらい |
| **2 択** (オン/オフ) | `<Switch>` | 数値ではなく状態 |
| **多数の選択肢** (15 個以上) | `<Select>` | stepper だと連打が必要、大きな数の入力に向かない |

## アクセシビリティ

- **`+` / `−` の aria-label**: デフォルトは「増やす」「減らす」。複数 NumberInput が並ぶ場合は文脈を入れた個別ラベルに (`decrementLabel` / `incrementLabel`)
- **境界で自動 disabled**: `value <= min` で `−` ボタン disabled、`value >= max` で `+` ボタン disabled。SR は「ボタン、無効」と読み上げる
- **キーボード操作**: `Tab` で `−` → `+` の順に focus、`Enter` / `Space` で発火 (button 標準)。フォーカス時は `focus:` 系で可視化 (現実装は color-only、将来 ring-focus へ統一予定)
- **タッチターゲット**: sm (40px) / md (48px)。md 以上で WCAG 2.5.5 達成。連打して値を増減することが多いため、密集 UI でも md 推奨
