## 概要

長いリストを **ページ分割して移動するための番号ナビゲーション**。前/次ボタン + 番号 button + ellipsis (`…`) で省略表示。`showEdges` で « » (最初/最後ジャンプ) を追加可能。`totalPages <= 1` のときは描画されない (1 ページしかなければ pagination 不要)。無限スクロール / ロード追加で十分なフィード型 UI には使わず、明示的にページ単位で見せたいデータ (検索結果・テーブル等) に。

<DoDontExample
  label="件数表示と組合せる (「N 件中 X-Y 件」)"
  doExample={
    (() => {
      function Demo() {
        const [p, setP] = useState(3);
        const perPage = 10;
        const total = 47;
        return (
          <div className="space-y-2">
            <p className="text-sm text-onSurface-muted">
              全 {total} 件中 {(p - 1) * perPage + 1}〜{Math.min(p * perPage, total)} 件
            </p>
            <Pagination currentPage={p} totalPages={Math.ceil(total / perPage)} onPageChange={setP} />
          </div>
        );
      }
      return <Demo />;
    })()
  }
  doCaption="件数表示と Pagination を併置すると「何件中の何件目を見ている」が明確で、ユーザーが全体感を掴める。"
  dontExample={
    (() => {
      function Demo() {
        const [p, setP] = useState(3);
        return <Pagination currentPage={p} totalPages={5} onPageChange={setP} />;
      }
      return <Demo />;
    })()
  }
  dontCaption="Pagination だけだと全何件か分からず、ユーザーが「データの量」を把握できない。"
/>

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **無限スクロール** (フィード型) | (Intersection Observer 実装) | Pagination はページ単位、フィードは連続表示 |
| **「もっと見る」ボタン** | (Button + state) | 段階的にロードする UI は Pagination より単純 |
| **「次へ」だけのウィザード** (順番に進む) | (Stepper 実装) | Pagination は飛び番ジャンプ前提 |
| **動的にロードする検索結果** (cursor ベース) | (Custom cursor pagination) | 番号ではなく cursor で API 設計するパターン |

## 使用例（旧 story から移設・要精査）

> 旧 EdgeCases の usage 合成例。VR (Overview) からは外し、ドキュメントとして保持。要不要は後で個別判断。

**記事一覧ページ（件数表示 + Pagination + showEdges）** — リストの上に件数、下に中央寄せの Pagination を置く定番構成。

<div className="w-96 space-y-4">
  <p className="text-body-sm text-onSurface-muted">全 47 件中 1〜5 件を表示</p>
  <ul className="divide-y divide-border-subtle border border-border-subtle rounded-md">
    {['記事タイトル #1','記事タイトル #2','記事タイトル #3'].map((title) => (
      <li key={title} className="px-4 py-3 text-body-sm text-onSurface">{title}</li>
    ))}
  </ul>
  <div className="flex justify-center">
    <Pagination currentPage={1} totalPages={10} onPageChange={() => {}} showEdges />
  </div>
</div>

> `totalPages = 1` のときは **何も描画されない**（1 ページしかないときに pagination は不要）。記事一覧 page 全体（`max-w-container-narrow` + `space-y-section-sm`）の構成は Layout token のデモなので [Tokens / Layout](?path=/docs/tokens-layout--guideline) を参照。

## アクセシビリティ

- **`<nav aria-label="ページネーション">`**: 外側 nav にランドマーク + ラベル
- **`aria-current="page"`**: 現在ページの button に付与。SR は「現在のページ、5 ページ目」と読む
- **`aria-label` 個別化**: 各 button に「5 ページ目」「次のページ」「前のページ」「最初のページ」「最後のページ」と明示的に
- **disabled**: 最初 / 最後で前 / 次ボタンが disabled になり、SR にも伝わる
- **focus ring**: `focus-visible:ring-focus` でキーボード focus を明示
- **キーボード操作**: `Tab` で button 移動、`Enter` / `Space` で発火 (button 標準)。矢印キーでの page 内移動は未実装 (将来検討)
- **タッチターゲット**: sm (28px) / md (32px) / lg (40px)。WCAG 2.5.5 (44×44px) は lg で達成。dense UI で sm を使う場合は隣接 button の余白に注意
