## 概要

トリガーの近くに浮かせて補助情報や軽い操作を出す非モーダルの overlay。native の `popover` 属性で top-layer 表示・外側クリック / Esc での light-dismiss をブラウザ標準に委ね、位置決めだけ `@floating-ui/dom` (offset / flip / shift) で行う。背景を遮断して確認させたい操作には Popover ではなく `<Modal>` を使う。

`DropdownMenu` (複数アクションのメニュー) と `Tooltip` (hover ヒント) は、この Popover を土台に積む予定 (ロードマップは `design-system-strategy.md`)。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべきコンポーネント | 理由 |
|---|---|---|
| **背景を遮断して確認させる** (不可逆操作) | `<Modal>` | focus trap + 背景遮断。外側クリックで消えては困る |
| **ホバーで出る短いヒント** | `<Tooltip>` (将来) | hover/focus で出る補助。現状は未実装 |
| **複数アクションのメニュー** | `<DropdownMenu>` (将来) | `menu` / `menuitem` の roving。現状は Popover で代用可 |
| **ページ内に常設する通知** | `<Alert>` | 常時表示・overlay ではない |

## アクセシビリティ

- **native `popover="auto"`**: top-layer 表示 / 外側クリック・Esc での light-dismiss をブラウザ標準に委ねる (自前の outside-click 監視より堅牢)
- **`role="dialog"` + `aria-label`**: パネルの用途を SR に伝える。見出しが無い場合は `aria-label` を指定する
- **トリガーの ARIA を自動付与**: `aria-haspopup="dialog"` / `aria-expanded` (開閉に連動) / `aria-controls` (パネル id)
- **フォーカス管理**: 開くとパネル内の最初の focusable (無ければパネル本体) へ移動。閉じると trigger へ戻す (外側の別コントロールを押して閉じた場合は focus を奪わない)
- **非モーダル**: focus trap は張らない。背景操作をブロックしたい確認は `<Modal>` を使う
- **アニメーション**: `prefers-reduced-motion` は preset でグローバル対応済 (個別対応不要)
