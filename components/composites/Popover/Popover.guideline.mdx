## 概要

役割「補足」の部品。押した要素についての説明や軽い操作を出す。読み流せるもので、外を押すと閉じる。**狭い幅 (画面の幅 640px 未満) では画面の下から、広い幅では押した要素の近くに出る。どちらで出すかは部品が決め、使う側は選ばない**。見出しの `title` は必須で、狭い幅では面の見出し、広い幅ではパネルの読み上げ名になる (広い幅の見た目には見出しを出さない)。

選択肢・操作から 1 つを選んで閉じるのは `Menu`、hover / focus の短い補足は `Tooltip`、戻せない操作の確認やまとまった入力は `<Modal>` を使う。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべきコンポーネント | 理由 |
|---|---|---|
| **背景を遮断して確認させる** (不可逆操作) | `<Modal>` | 外を押しても閉じない。Popover は外を押すと閉じる軽いものだけ |
| **ホバーで出る短いヒント** | [`<Tooltip>`](?path=/docs/composites-tooltip--guideline) | hover / focus で出る短い補助 |
| **選択肢・操作から 1 つ選ぶ** | [`<Menu>`](?path=/docs/composites-menu--guideline) | `menu` / `menuitem` の矢印キー移動。選んだら閉じる |
| **ページ内に常設する通知** | `<Alert>` | 常時表示・overlay ではない |

## アクセシビリティ

- **入口の ARIA を自動で付ける**: `aria-haspopup="dialog"` / `aria-expanded` (開閉に連動) / `aria-controls` (出ている形の面・パネル)
- **名前**: どちらの幅でも `title` が名前になる。広い幅はパネル (`role="dialog"`) の `aria-label`、狭い幅は面 (`<dialog>`) の見出し (`aria-labelledby`)
- **開いた直後のフォーカス (どちらの幅でも同じ)**: 中の最初の押せるもの。無ければ面・パネルそのもの (中身が文だけのとき)。狭い幅の閉じるボタンには最初のフォーカスを当てない。閉じたら入口に戻す (外の別の押せるものを押して閉じたときは、そちらへ移ったフォーカスを奪わない)
- **広い幅の形**: native `popover="auto"` で、外を押す / `Esc` で閉じる。フォーカスは閉じ込めない (非モーダル。Tab でパネルの外へ出られる)
- **狭い幅の形**: 下から出る面 (`<dialog>` の `showModal()`)。開いている間は背景を操作できず、背景はスクロールしない。`Tab` は面の中 (中身と閉じるボタン) を回る。閉じるのは `Esc`・外を押す・閉じるボタン・上端の帯を下に引く。帯を引くのは指の近道で、同じことは閉じるボタンと `Esc` でできる。中身は本文の大きさ (`type-body`) で出す
- **Modal の中に置いたとき**: `Esc`・外を押す 1 回で閉じるのは Popover だけ (Modal は開いたまま)
- **タッチ**: 狭い幅の面は、開いてから 300ms は押しても反応しない (入口の二度押しが、上がってくる面に当たらないように)
- **フォーカスの輪**: 面・パネルそのものにフォーカスが来たときは内側 2px の輪 (`focus-ring-inset`)。指・マウスで開いたときは、開いた直後にフォーカスは移すが、キーを押すまで輪を出さない (キーボード・外から `open` で開いたときは、はじめから出す)。指・マウスで閉じて入口に戻したフォーカスも、次にキーを押すか入口から離れるまで輪を出さない (形の使い分けは AGENTS.md §3-2「フォーカスの規則」)
- **幅が変わったとき**: 開いている間に幅が 640px をまたいだら閉じる (形を入れ替えない)
- **アニメーション**: 狭い幅の面は下から出る (200ms)。`prefers-reduced-motion` では動かさない

## 関連

### 内部で利用するコンポーネント

- `<Button>` — `trigger` に渡す代表例 (任意の focusable 要素を渡せる)。狭い幅の面の閉じるボタン

### 依存

- [`@floating-ui/dom`](https://floating-ui.com/) — 広い幅のパネルの位置決め (offset / flip / shift + autoUpdate) のみに使用

### 同じ仕組みを使う部品

- [`<Menu>`](?path=/docs/composites-menu--guideline) — 狭い幅で下から出る面と、広い幅で押した要素の近くに出す仕組みが同じ
