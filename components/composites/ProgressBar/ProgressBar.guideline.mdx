## 概要

進捗を表すインジケーター。`value` (現在値) / `max` (最大値) で割合を表現する **determinate モード** と、`indeterminate` で処理中だけを示す **indeterminate モード** をサポート。`role="progressbar"` + `aria-valuenow/min/max` を自動付与し、SR にも進捗が伝わる。アップロード進捗・ステップ表示・残り容量等に。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **ステータスを 1 つの単語で** ("送信中" 等) | `<Badge>` / `<Spinner>` | 数値の進捗ではなく状態の表示 |
| **進捗が秒以下で終わる** (ボタン送信中等) | `<Spinner>` / Button loading 状態 | バー表示する前に終わる |
| **数値そのもの** (¥3,000 / ¥5,000 等の金額) | (テキスト + Typography) | バーは比率を見せる用途、絶対値は数値で |

## アクセシビリティ

- **`role="progressbar"`**: 自動付与、SR が「プログレスバー」として認識
- **`aria-valuenow` / `aria-valuemin` / `aria-valuemax`**: 数値情報を SR に伝達。indeterminate 時は `aria-valuenow` を出さない
- **`aria-label`**: `label` prop の値、無ければ `${percentage}%` か「処理中」(indeterminate)
- **`aria-busy="true"`**: indeterminate モードのとき自動付与、SR が「処理中」と読み上げる
- **色だけに頼らない**: status (error / warning) は label テキストでも明示
- **不確定の長時間表示は避ける**: SR / 認知特性によっては indeterminate アニメーションが負担。数十秒以上かかる場合は polling で determinate に切り替える検討
