## 概要

**複数の選択肢から 1 つを排他選択** するラジオボタン。常に `<RadioGroup>` でラップして使い、`<fieldset>` + `<legend>` で SR にもグループ用途が伝わる。`name` 属性が同じ Radio 同士で排他制御。3〜5 個の選択肢で「常に全候補を見せたい」場面に最適。6 個以上は `<Select>`、2〜5 個の表示切替は `<SegmentedControl>`、即座反映設定は `<Switch>` を検討。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **多数の選択肢** (6 個以上) | `<Select>` | 一覧性ではなく省スペース・スクロール対応 |
| **少数の表示切替** (リスト/グリッド等) | `<SegmentedControl>` | フォーム入力ではなく表示切替 |
| **即座反映の ON/OFF** | `<Switch>` | フォーム送信ではなく即時反映 |
| **複数選択可能** | `<CheckboxGroup>` | 排他制御ではない |

## 使用例（旧 story から移設・要精査）

> 旧 EdgeCases の usage 合成例。VR (Overview) からは外し、ドキュメントとして保持。要不要は後で個別判断。

**多数の選択肢（5+ は縦並び、6+ なら Select 検討）** — 縦並びで一覧性を確保。選択肢が増えるほど Select の方が省スペース。

  <Radio name="ex-pref" value="埼玉県" label="埼玉県" />

  <Radio name="ex-pref" value="茨城県" label="茨城県" />

**注文フォーム（お支払い + 配送方法を Layout 枠に）** — `max-w-container-narrow` + `space-y-section-sm` に description 付き RadioGroup を 2 つ積む。

## アクセシビリティ

- **`<fieldset>` + `<legend>`**: RadioGroup が自動生成、SR はグループ + legend を読み上げ
- **`name` 属性**: 同じ name の Radio で排他制御。`role="radiogroup"` 相当の挙動を browser が標準実装
- **`aria-invalid` + `aria-describedby`**: error / helpText / errorMessage と関連付け自動
- **キーボード操作**: `Tab` でグループにフォーカス、`↑` `↓` `←` `→` で選択肢間移動 (browser 標準)。`Space` / `Enter` で選択
- **disabled 時**: グループ全体 or 個別 Radio で。SR にも「無効」が伝わる
- **focus ring**: 各 Radio に focus 時のリング表示
- **タッチターゲット**: 20×20px (1 サイズ運用、Checkbox と整合)。input 自体は 20px だが `<Label htmlFor>` でラベルもクリック領域、ラベル含めて WCAG 2.5.5 (44×44px) を達成
