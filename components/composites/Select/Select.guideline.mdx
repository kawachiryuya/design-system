## 概要

ネイティブの `<select>` をラップしたドロップダウン選択。**多数の選択肢から 1 つ排他選択** する用途で、ブラウザ標準のドロップダウン挙動 / OS ネイティブ UI / SR 完全対応 / モバイルでのネイティブ picker 起動など、自前実装の dropdown では得難い恩恵を享受できる。Discriminated union 型で error 状態時は `errorMessage` が型レベルで必須。2〜5 個の選択肢には `<SegmentedControl>` / `<Radio>` を検討。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **2〜5 個の排他選択** | `<SegmentedControl>` / `<Radio>` | 一覧性が高く 1 クリックで切替 |
| **複数選択** | `<CheckboxGroup>` / Custom multi-select | Select は単一選択用 |
| **テキスト自由入力 + 候補** | `<SearchBar>` (将来 Autocomplete) | ネイティブ Select では検索不可 |
| **Modal 経由でフィルタ複数選択** | `<FilterChip>` + Modal | フィルター UI の文脈 |

## アクセシビリティ

- **ネイティブ `<select>`**: OS / ブラウザの標準 dropdown 挙動・キーボード操作・SR 対応をそのまま継承
- **`<Label htmlFor>`**: 自動配線、ラベルクリックで focus
- **`aria-invalid="true"`**: error=true 時に自動付与
- **`aria-describedby`**: error 時は errorMessage の id、通常時は helpText の id と関連付け
- **`aria-required="true"`**: required=true 時に自動付与
- **focus 表現**: border 色変化 + inset ring (input/textarea と同パターン、UA heuristic 問題回避)
- **タッチターゲット**: sm (40px) / md (48px) / lg (56px)。md 以上で WCAG 2.5.5 達成
- **キーボード操作**: ネイティブ標準。`Tab` で focus、`Space` / `↑` / `↓` で開閉、選択肢への文字打鍵で検索 (browser 標準)
