## 概要

オン/オフの切り替えを表す **トグルスイッチ**。`role="switch"` + `aria-checked` で SR にも状態が伝わる。**即座に反映される設定** (ダークモード切替・通知 ON/OFF 等) に使う。フォーム送信 (送信ボタンで確定する) の場合は `<Checkbox>` を使う。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **フォーム送信で確定する選択** (利用規約同意等) | `<Checkbox>` | フォーム送信モデルでは Checkbox が慣習 |
| **複数選択肢から 1 つ** | `<Radio>` / `<SegmentedControl>` | Switch は ON/OFF 2 値、選択肢が 3 つ以上には使わない |
| **アクション実行** (押すと処理発火) | `<Button>` | Switch は状態切替、アクションは Button |
| **数値の有効/無効** (0/1) | (用途次第で Switch でも Checkbox でも) | bool 値で「即座反映」なら Switch |

## アクセシビリティ

- **`role="switch"` + `aria-checked`**: 自動付与、SR は「スイッチ、オン/オフ」と読み上げる
- **`<Label htmlFor>`**: ラベルクリックでもトグルする (label と switch を関連付け)
- **キーボード操作**: `Tab` で focus、`Enter` / `Space` で発火 (Enter キー対応は handleKeyDown で実装、`<button>` 標準の Space に加えて)
- **focus ring**: `focus-visible:ring-focus` でキーボード focus のみリング表示
- **disabled 時の見せ方**: `opacity-disabled` + `cursor-not-allowed`。「なぜ disabled か」は description で補強
- **タッチターゲット**: track 44×24px (thumb 20px、片側 gap 2px)。トラックそのものは 44×24 だが button 要素全体がクリック領域、`<Label htmlFor>` でラベルも反応するため WCAG 2.5.5 の 44×44px はラベル含めて達成可
