## 概要

**同階層内の表示切替** を行う UI。下線で active を示す Carbon / Material 風のタブ。`role="tablist"` / `role="tab"` / `role="tabpanel"` 自動付与、`← → ↑ ↓ Home End` 全対応のキーボードナビゲーション、controlled / uncontrolled 両対応、バッジ表示、disabled タブのスキップ移動など a11y を完全実装。ページ全体の切替には Routing、深い階層には `<Accordion>` を検討。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| **ページ全体の切替** | (Routing) | URL ごとに分けるべき。Tabs はページ内専用 |
| **多数のセクション折りたたみ** (FAQ 等) | `<Accordion>` | 縦に並べて開閉、Tabs は横並び |
| **2〜5 択の排他 input** | `<SegmentedControl>` / `<Radio>` | フォーム入力用、Tabs は表示切替 |
| **多数のタブ + ドリルダウン** (深い階層) | (Sidebar / Tree) | Tabs は浅い切替向け |

## アクセシビリティ

- **`role="tablist"` / `role="tab"` / `role="tabpanel"`**: 自動付与、WAI-ARIA 1.2 標準
- **`aria-selected` / `aria-controls` / `aria-labelledby`**: tab ↔ panel の関連付けを自動配線
- **`tabIndex` 管理**: active タブのみ `tabIndex=0`、他は `tabIndex=-1` (Roving tabindex)。Tab キーで tabpanel へ抜けられる
- **キーボード操作 (既定 = automatic activation)**: `← → ↑ ↓` 矢印で隣のタブへ移動 = **即時選択** (disabled スキップ)、`Home` / `End` で先頭/末尾、`Enter` / `Space` でも選択
- **`activationMode="manual"` (遅延ロード panel 向け)**: 矢印移動が即選択だと、panel が遅延ロード / 通信を伴う場合に矢印連打のたび fetch が走る。`activationMode="manual"` にすると矢印は **focus のみ移動**し、`Enter` / `Space` で選択確定する (WAI-ARIA APG の manual activation)。重い panel では manual を推奨
- **不正な activeId のフォールバック**: controlled で `tabs` に無い `activeId` が来た場合は `tabs[0]` にフォールバック (開発時は console.warn)。全 panel が消える事故を防ぐ
- **focus ring**: `focus-visible:ring-focus` でキーボード focus 時のみリング表示
- **無効タブ**: native `disabled` 属性のみ付与 (支援技術に「無効」が伝わり、矢印移動・Tab からもスキップされる)
- **タッチターゲット**: タブの padding は px-4 py-2 (16px+8px)。WCAG 2.5.5 (44×44px) は label の長さ次第。極小ラベルでは余白を追加検討
