## 概要

トリガーに hover / focus したとき、その近くに**短い補足テキスト**を浮かせる。アイコンのみのボタンの説明、省略表示の全文、補助的なヒントなどに使う。`<Popover>` と同じ overlay 基盤 (native `popover` + `@floating-ui/dom`) を共有しつつ、表示は hover / focus + 遅延、意味づけは `role="tooltip"` + `aria-describedby` で行う。

**読み上げ補足であって操作対象ではない**。tooltip の中に button / link などの操作要素は入れない (フォーカスもできない)。操作や複数行の内容が要るなら `<Popover>` を使う。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべきコンポーネント | 理由 |
|---|---|---|
| **操作 / 複数行 / リッチな内容** | `<Popover>` | tooltip 内はフォーカス・操作できない |
| **選択して実行するメニュー** | `<DropdownMenu>` | menu/menuitem の操作対象 |
| **常時見せたい注意書き** | `<Alert>` / 補助テキスト | hover/focus に隠さず常設する |
| **入力欄の説明・エラー** | `<Label>` / フィールドの説明文 | フォーム要素に紐づく恒常的な説明 |

## アクセシビリティ

- **`role="tooltip"` + `aria-describedby`**: トリガーに `aria-describedby` を自動付与し、tooltip を「補足の説明」として紐づける (名前を置き換える `aria-labelledby` ではない)
- **hover と focus の両方で表示**: focus 時は即時表示 (キーボード / SR)、hover 時は `delay` 後に表示
- **WCAG 1.4.13 (Content on Hover or Focus)**:
  - **Dismissible**: 表示中は `Esc` で閉じられる (ポインタ / フォーカスを動かさずに消せる)
  - **Hoverable**: tooltip 上にポインタを移しても消えない (trigger→tooltip 間に猶予あり)
  - **Persistent**: 自動では消えず、hover / focus が外れるまで表示し続ける
- **トリガーは focusable**: `<Button>` / `<Link>` 等、または `tabIndex={0}` を持つ要素にする (素の `<span>` 等は不可)
- **content は非操作テキスト**: tooltip はフォーカスできないため、button / link を入れない
- **`prefers-reduced-motion`**: preset でグローバル対応済 (個別不要)
