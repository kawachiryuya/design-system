## 概要

ユーザーがその場でアクションを実行するためのトリガー。送信・保存・削除など「押すと何かが起きる」操作に使う。別ページへの遷移には Button ではなく `<Link>` を使う。

### 別コンポーネントの方が適切な場面

「これは Button じゃないかも?」と迷ったときは下の表で目的に合うコンポーネントを探す:

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| 押すと **URL に遷移** する | `<Link>` | `<a>` でないと OS 機能 (右クリック新タブ等) / SEO が効かない |
| 押すと **ON/OFF が永続化** する | `<Switch>` | 状態を表現するのが本義のコントロール |
| 押すと **選択状態が変わる** (複数候補から1つ) | `<SegmentedControl>` / `<Radio>` | 「選択」と「実行」は別 UI |
| 押すと **モード切替** する (1ボタンで ON/OFF) | `<ToggleButton>` | 押下=状態切替の専用 UI |
| **フィルタ条件** を足し引きする | `<FilterChip>` | 検索結果に作用する選択は専用パターン |
| ナビゲーションの **タブ切替** | `<Tabs>` | 「複数候補から1つを選ぶ」UI、Button はアクション実行 |
| **メニュー** を開く (複数アクションを内包) | `<Modal>` (暫定) | 専用の `<DropdownMenu>` は未実装。複数アクションを1ボタンに集約する必要があれば現状 `<Modal>` で代用 |

## アクセシビリティ

- **キーボード**: `Tab` でフォーカス移動、`Enter` / `Space` でクリック
- **状態**: `disabled` 時は DOM 上も `disabled` 属性、`isLoading` 時も `disabled` でクリック不能化
- **フォーカス可視化**: `focus-visible:ring-2` で2px のリングを標準装備
- **タッチターゲット**: `size="md"` / `large` で WCAG 2.5.5 (44x44px) を満たす。`size="sm"` は密度の高い一覧 UI に限定する
- **icon-only**: `aria-label` を型レベルで必須化済 (`<Button iconOnly icon={...} aria-label="閉じる" />`)
