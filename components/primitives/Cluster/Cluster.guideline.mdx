## 概要

子要素を水平方向に並べ、画面端で自動折り返しする layout primitive。`gap` で 6 段階 (Stack と同じスケール) の間隔を選び、`align` で cross-axis (垂直) 配置、`justify` で main-axis (水平) 配置を制御する。**常に折り返す** (`flex-wrap` 固定) のが Cluster の定義的特徴。

**実装は `flex flex-wrap + gap-*`**。non-wrap 用途は plain な `flex items-center gap-N` を直接書いた方が簡潔。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| 縦並び (form / list 等) | `<Stack>` | Cluster は水平専用、垂直は Stack の責務 |
| max-width で中央寄せ | `<Center>` | Center は単列 horizontal centering、Cluster は children の inline 並び |
| 折り返さない horizontal | plain `flex items-center gap-N` | Cluster の wrap は無効化できない (定義的特徴)、non-wrap には不適 |
| Tabs / SegmentedControl | `<Tabs>` / `<SegmentedControl>` (既存 composite) | active state 等の振る舞いを伴う UI は専用 composite に |
| 2 列以上の grid | `<TwoColumn>` (Phase B 予定) / `grid grid-cols-*` | Cluster は単一行 (折り返しはあるが grid ではない)、2col 構造は別 |

## アクセシビリティ

- **`as` で semantic タグを保つ**: navigation なら `as="nav"`、繰り返し項目なら `as="ul"` (子は `<li>`)。SR / browser reader-mode / landmark navigation で正しく認識される
- **`align="baseline"` と typography**: 異なる font-size の inline 要素を並べる時、baseline 揃えにすると視覚的に揃って見える (text と icon、見出し+補足等)
- **gap と reading order**: gap は視覚的な余白のみ。読み上げ順序は DOM 順そのまま (flex-row による視覚順 = DOM 順)
- **flex-wrap と RTL**: flex / gap は CSS logical、RTL でも自動反転する

### 内部で利用するコンポーネント

なし。Cluster は単独で完結する Layout primitive。

### Cluster を内部で使う代表的なコンポーネント / 使い方

- AppShell (Phase B) の **Header menu / BottomNav button 列**
- Footer の utility link 列 (regulation / privacy / contact)
- `<FilterChip>` の group (折り返しで複数 chip を並べる)
- 記事メタ情報 (date / read time / view count を icon + label で並べる)
- header pattern (title 左 + action 右、`justify="between"`)
- breadcrumb (`xs` gap で密接した item 列、separator 込み)
