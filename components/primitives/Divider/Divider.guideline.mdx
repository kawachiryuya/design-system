## 概要

セクション間の視覚的な区切り。`role="separator"` を自動付与し、SR にも区切りが伝わる。`orientation` で水平 (`<hr>`) / 垂直 (`<div>`) を切り替え、`label` で「または」などの意味的な区切り (text + 線 + 線) を表現できる。`weight` で線の太さを `thin` (1px、標準) / `normal` (2px、強調) に切り替え可能。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| 見出しで階層を作る | `<Typography variant="h*">` | 区切り線で階層を作るのは過剰。font-size / weight で表現 |
| Card / Modal の枠線 | `<Card>` / `<Modal>` | コンテナの責務、Divider は内部の区切り専用 |
| ステータスを示す色帯 | `<Alert>` の bar / `<Badge>` | 区切り線は意味を持たない、色で意味を伝えるなら別 |
| ナビゲーションのインジケーター | `<Tabs>` の under-line | tab 切替の active 表示は Tabs の責務 |

## アクセシビリティ

- **`role="separator"`**: SR が「区切り」として認識し、セクション境界を伝えられる
- **`aria-orientation="vertical"`**: 垂直方向時に明示。デフォルトは horizontal
- **`aria-label` (label 指定時)**: 「または」「以上」などの意味的区切りを SR に伝達
- **線のコントラスト (1.4.11)**: `border-border-muted` (`#e5e5e5`) は AA UI 部品要件 (3:1) ギリギリ。明確な区切りが必要なら weight を normal にして視認性を上げる
- **装飾だけの目的では使わない**: ARIA `role="separator"` がノイズになる場合は `<div className="border-t border-border-muted" />` のような plain な装飾 div を使う

## 関連

### 内部で利用するコンポーネント

なし。Divider は単独で完結する Primitive。

### Divider を内部で使う代表的なコンポーネント

- `<Card>` の footer 上 — content と action の区切り
- `<Modal>` の header 下 / footer 上 — title / body / actions の区切り
- 設定画面 / プロフィール画面 — セクション間の区切り
- フッターのリンク群 (vertical) — utility リンクの区切り
