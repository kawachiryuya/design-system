## 概要

SVG アイコンのラッパー。`name` 経由で `iconRegistry` の登録済みアイコンを描画するのが基本パターン。`children` でカスタム SVG パスを直接渡すことも可能 (registry に無いアイコンの一時利用や product 固有アイコン)。サイズ・色・アクセシビリティの ARIA 属性を統一管理する。

利用可能な `name` の全一覧はサイドバーの [**Library story**](?path=/story/primitives-icon--library) を開いて確認する。registry にないアイコンを追加したい場合は [`components/primitives/Icon/iconRegistry.ts`](./components/primitives/Icon/iconRegistry.ts) に追記する。

### 別コンポーネントの方が適切な場面

「これは Icon じゃないかも?」と迷ったときは下の表で目的に合うコンポーネントを探す:

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| ロゴ / 商標 / プロダクト固有のグラフィック | `<img>` か `<Image>` | アイコン体系の整合性 (size / color) に乗らない |
| ボタンとして押せるアイコン | `<Button iconOnly icon={...} aria-label="...">` | クリック領域 + フォーカス + 役割の Button responsibilities が要る |
| 状態を示すドット / バッジ | `<Badge>` | テキストや数値と組み合わせるなら Badge |
| 装飾的な区切り線 | `<Divider>` | 横線や縦線はアイコンではなく Divider |

## アクセシビリティ

- **意味のあるアイコン (label あり)**: `role="img"` + `aria-label` が自動付与。SR で意味が伝わる
- **装飾アイコン (label なし)**: `aria-hidden="true"` が自動付与。SR から無視される (隣接テキストが本体)
- **キーボード**: SVG 自体は `focusable="false"` で Tab 移動から除外。クリック可能なアイコンは `<Button iconOnly>` で包む
- **色のみの意味禁止**: アイコンの色 (error 赤、success 緑等) だけに意味を載せず、必ず **label + テキスト** の冗長表現で意味を伝える
- **コントラスト**: `color="disabled"` (`#a3a3a3`) は WCAG 1.4.11 (3:1) を満たす UI 部品色

関連: [Tokens / Color (Semantic)](?path=/docs/tokens-color-semantic--guideline)

## 関連

### 内部で利用するコンポーネント

なし。Icon は単独で完結する Primitive。

### Icon を内部で使う代表的なコンポーネント

- `<Button icon={<Icon ...>}>` / `<Button iconOnly icon={<Icon ...>}>` — Button の icon prop に渡す
- `<Link external>` — `external` 時に内部で `open_in_new` アイコンを描画
- (将来) `<Input leadingIcon={...} trailingIcon={...}>` — フォーム入力欄のアイコン
- `<Alert>` / `<Toast>` — variant ごとの状態アイコン
