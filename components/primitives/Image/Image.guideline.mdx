## 概要

`<img>` のラッパー。アスペクト比固定 / object-fit / 読み込みエラー時の fallback / `loading="lazy"` を統合管理する。**`alt` 属性を型レベルで必須化**し、意味のある画像は説明文字列、装飾画像は空文字 `""` を明示的に渡すことで `role="presentation"` を自動付与する。

`aspectRatio` を指定すると container div で wrap して absolute 配置するため、画像読み込み完了前から **レイアウトシフトが発生しない**。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| アイコン / 記号 | `<Icon>` | `<Image>` は raster / 写真、`<Icon>` は SVG ベクター |
| プロフィール画像 + イニシャル fallback | `<Avatar>` | 顔写真特化、欠落時イニシャル表示の専用 UI |
| 読み込み中の placeholder | `<Skeleton variant="rectangular">` | 画像の読み込み中表示は Skeleton |
| 装飾の背景画像 (テキスト被せ等) | `background-image` CSS | `<img>` ではなく div の背景に |

## アクセシビリティ

- **`alt` 型レベル必須**: TypeScript で alt 省略時に compile error。「忘れる」が原理的に起きない
- **装飾画像は `alt=""`**: 空文字を渡すと `role="presentation"` 自動付与で SR から無視される
- **`loading="lazy"` デフォルト**: 初期描画パフォーマンス向上。above-the-fold は明示的に `lazy={false}`
- **エラー fallback**: `onError` で自動切替、視覚的に「壊れた」状態を見せない
- **画像の意味**: 隣接テキストで意味が完結するなら装飾扱い、写真自体が情報なら descriptive alt

## 関連

### 内部で利用するコンポーネント

- `<Icon>` — 読み込みエラー時のデフォルト fallback の placeholder アイコン (`name="image"`)

### Image を組み合わせる代表的なコンポーネント

- `<Card>` のサムネイル — ブログ記事カードなどで video 比率の Image をヘッダーに
- `<Avatar>` — 内部実装で Image を使用 (alt + 円形 + イニシャル fallback)
- `<Modal>` の画像ライトボックス — auto + max-w で表示
