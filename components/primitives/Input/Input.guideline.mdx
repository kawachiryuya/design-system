## 概要

1 行のテキスト入力を受け付ける最小単位のフォームコンポーネント。**ラベル / ヘルプテキスト / エラーメッセージを一体管理** し、a11y 属性 (`aria-invalid` / `aria-describedby` / `aria-required`) を自動付与する。`error` と `errorMessage` は **discriminated union** で型レベルにセット必須化済で「エラー色だけで errorMessage 忘れ」が原理的に起きない。

`type` で `email` / `password` / `number` 等を切替えるとモバイルでキーボードレイアウトが最適化される。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| 複数行のテキスト (コメント・説明文) | `<Textarea>` | 改行できる入力は別コンポーネント |
| 数値スピナー (± ボタン / step 操作) | `<NumberInput>` | 数値の増減 UI は専用パターン |
| 候補表示 / 履歴付き検索 | `<SearchBar>` | 検索バーは UI 慣習が独立 |
| 選択肢から 1 つ選ぶ | `<Select>` / `<Radio>` / `<SegmentedControl>` | 「入力」ではなく「選択」 |
| 複数選択 | `<Checkbox>` / `<CheckboxGroup>` | フラグの組合せは別 UI |
| ON/OFF の真偽値 | `<Switch>` / `<Checkbox>` | 2 値は専用コントロール |
| 日付範囲 / カレンダー UI | (将来) `<DatePicker>` | `type="date"` はネイティブ UI のみ |

## アクセシビリティ

- **`<label htmlFor>` 自動連携**: `label` prop 指定で自動。クリックでフォーカス、SR がラベルを読む
- **`aria-required`**: `required` 時に自動付与
- **`aria-invalid`**: `error: true` 時に自動付与
- **`aria-describedby`**: `errorMessage` または `helpText` の id と自動関連付け
- **`role="alert"`** (FormMessage 内部): エラーメッセージ表示時に SR が即時通知
- **キーボード**: `Tab` でフォーカス、`Enter` でフォーム送信
- **タッチターゲット**: `size="medium"` 以上で WCAG 2.5.5 (44x44px) を満たす。`small` は密集 UI 限定
- **placeholder 色**: `text-onSurface-muted` (#737373) で AA 4.69:1 を満たす
- **エラー色のみで伝えない**: `errorMessage` (型レベル必須) で言葉でも伝える

## 関連

### 内部で利用するコンポーネント

- `<Label>` — ラベル描画 + required `*` マーク + disabled 連動
- `<FormMessage>` (内部 `_internal/`) — helpText / errorMessage の表示と aria 関連付けを統括

### Input と組合せて使う代表的なコンポーネント

- `<Button>` — フォーム送信ボタン
- `<Checkbox>` / `<Radio>` — 同じフォーム内の選択コントロール
- `<Select>` — 選択肢のドロップダウン
- `<Textarea>` — 複数行入力 (Input の自然な拡張)
