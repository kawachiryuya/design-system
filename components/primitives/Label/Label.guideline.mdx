## 概要

フォームフィールドのラベル。**`<label htmlFor>` で input と紐づける** ことが本義で、視覚表示と SR 読み上げを一致させる。`required` (必須マーク `*`) と `optional` (任意マーク「（任意）」) で必須/任意の状態を視覚的・a11y 的に伝える。同時指定時は `required` が優先される。

### 別コンポーネントの方が適切な場面

「これは Label じゃないかも?」と迷ったときは下の表で目的に合うコンポーネントを探す:

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| 見出し / 段落のテキスト装飾 | `<Typography>` | Label は `<label>` 専用、`htmlFor` を持たない用途には Typography |
| ステータス / カテゴリのバッジ | `<Badge>` | 短いラベル表示でも form と無関係なら Badge |
| ボタン内のテキスト | `<Button>` の children | Label は入力欄に対応する説明テキスト |
| 何かを補足する説明文 (form 入力欄の下のヘルプテキスト等) | `<Typography variant="caption" color="muted">` | フィールドの説明は label とは別 |

## アクセシビリティ

- **`<label htmlFor>` 必須**: input の `id` と結ぶことで SR が両者の関係を認識。label クリックで input にフォーカスが当たる
- **必須マーク**: `*` の span に `aria-label="必須"` を自動付与。SR で「必須」と読まれる
- **任意マーク**: 「（任意）」は通常テキストとして読まれる。色は `text-onSurface-muted` (#737373 = 4.69:1) で AA 通常テキスト要件を満たす
- **disabled 連動**: `disabled` 時は `text-onSurface-disabled` + `cursor-not-allowed`。input 側の disabled と必ず連動させる
- **色のみの意味禁止**: 必須は色 + 記号 (`*`) + SR テキスト (`aria-label`) の三重表現で伝える

## 関連

### 内部で利用するコンポーネント

なし。Label は単独で完結する Primitive (span を使った required/optional マーカーは内部実装)。

### Label を組み合わせる代表的なコンポーネント

- `<Input>` / `<Textarea>` — フォーム入力欄と組合せ、`htmlFor` で結ぶ
- `<Checkbox>` / `<Radio>` / `<Switch>` — 選択コントロールと組合せ
- `<Select>` — セレクトボックスのラベル
