## 概要

`<a>` 要素のラッパー。**押すと URL に遷移する** 操作に使う。外部リンクの `target="_blank"` / `rel="noopener noreferrer"` / 外部アイコン / `aria-disabled` を自動で付与する。遷移を伴わないアクション (送信・保存・削除等) には `<Button>` を使う。

### 別コンポーネントの方が適切な場面

「これは Link じゃないかも?」と迷ったときは下の表で目的に合うコンポーネントを探す:

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| 押すと **アクションが実行** される (保存・送信・削除) | `<Button>` | URL を持たない操作はボタン。SR の役割も `button` |
| **タブ切替** で URL を変えない | `<Tabs>` | URL を変えないなら「選択」のコントロール |
| **モーダル / Drawer を開く** | `<Button>` + onClick | URL を持たないなら Button |
| 単なる **テキストの色付け** | `<Typography>` 等 | Link は "押せる" 期待を生むので装飾用には使わない |
| **階層ナビゲーション** | `<Breadcrumb>` | 内部で Link を使う専用コンポーネント |
| **ページ番号遷移** | `<Pagination>` | 内部で Link を使う専用コンポーネント |

## アクセシビリティ

- **`<a href>`**: ネイティブ要素を使うので SR / OS 機能 (右クリック新タブ等) がフル機能
- **`disabled`**: `aria-disabled="true"` + `href` 削除でフォーカス移動を防ぐ
- **外部リンク**: `rel="noopener noreferrer"` を自動付与 (タブナビゲーション攻撃 / 性能影響の防止)
- **外部アイコン**: `aria-label="外部リンク"` 付きで描画、SR にも「外部リンク」が伝わる
- **フォーカス可視化**: `focus-visible:ring-2` でキーボード操作を明示
- **リンクテキスト**: 「こちら」「クリック」を避け、遷移先が分かる言葉に (SR の「リンク一覧」機能で意味が取れる)
- **色覚多様性**: `underline="none"` は周辺と区別が付くナビゲーション等に限定。本文中は `underline="always"` か `hover` を使う
