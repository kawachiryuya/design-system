# Link — Guideline

Props 表 / コード例 / 状態の見え方は **Docs (autodocs)** と **Stories タブ** を参照。
本ページは「なぜそう作るか」「いつどう使い分けるか」を扱う設計の指針。

---

## 概要

`<a>` 要素のラッパー。**遷移を伴う操作** に使う。
外部リンク時の `rel="noopener noreferrer"` / `target="_blank"` / 外部アイコン / `aria-disabled` を自動付与する。

---

## 使うとき

押下時に **URL に遷移** する場面に使う。代表シーンと組合せの手本:

### 本文中の参照

`color="primary"` + `underline="hover"` (デフォルト) で本文と区別。リンクテキストは「こちら」を避け、遷移先が分かる言葉にする。

```
詳細は<Link href="/docs">公式ドキュメント</Link>を参照してください。
```

### グローバルナビゲーション

`color="neutral"` + `underline="none"` で周辺と馴染ませ、hover / focus でフィードバック。

```
[ ホーム | サービス | 料金 | 会社概要 | お問い合わせ ]
```

### 外部サイトへの誘導

`external` を立てると `target=_blank` + `rel` + 末尾アイコンが付く。「外部リンクであること」をユーザーに事前に伝えられる。

```tsx
<Link href="https://example.com" external>公式ドキュメント</Link>
  → 「公式ドキュメント ↗」
```

### フッターの規約リンク

`color="muted"` + `underline="hover"` で控えめに。利用規約 / プライバシーポリシー等。

### 「もっと見る」 (カード末尾)

`color="primary"` で詳細ページへ遷移。Card 内のテキストとセットで使う。

---

## 使わないとき

遷移以外の挙動が要る場面では、別コンポーネントを使う:

| やろうとすること | 理由 | 使うべき別コンポーネント |
|---|---|---|
| 押すと **アクションが実行** される (保存・送信・削除) | URL を持たない操作はボタン | `<Button>` |
| **タブ切替** で URL は変えない | URL を変えないなら Tabs | `<Tabs>` |
| **モーダル / Drawer を開く** | URL を持たないなら Button | `<Button>` + onClick |
| 単なる **テキスト装飾** (色付け / 強調) | リンクは "押せる" 期待を生む | `<Typography>` 等 |

## color / underline の使い分け

### color

| color | 用途 |
|---|---|
| `primary` | 主要リンク / 本文中の参照 / CTA リンク |
| `neutral` | ナビゲーション / 見出し近くのリンク |
| `muted` | フッター / 規約 / 補足リンク |

### underline

| underline | 用途 |
|---|---|
| `always` | 本文中のリンク (リンクと即座に分かる) |
| `hover` | ボタン的なリンク / 本文中の標準 |
| `none` | ナビゲーション / 周辺と区別が付く場合のみ |

a11y 観点: 色だけで区別できない場合 (色覚多様性) は `underline` を有効にする。

## 利用ガイド

### 守ること (NG パターン)

| やりがちな誤り | 問題 | 正しいやり方 |
|---|---|---|
| 「こちら」「クリック」のような非説明的リンクテキスト | SR のリンク一覧で意味が取れない | 遷移先が伝わる文言にする (「利用規約」「公式ドキュメント」) |
| 色だけでリンクを示す (下線なし + 本文と同色) | リンクと気付かれない | `color` で区別、または `underline` を `always`/`hover` に |
| `target="_blank"` の予告なし | 突然新タブが開いて混乱 | `external` で末尾アイコン表示し予告 |
| 外部リンクで `rel="noopener"` 省略 | タブナビゲーション攻撃 / 性能影響 | 本コンポーネントは `external` で自動付与 |
| ナビゲーションリンクに `<button>` タグ | SEO / OS 機能 (右クリック新タブ) が効かない | 必ず `<Link>` |
| `<a>` を直書き | a11y / 外部リンク安全策の取りこぼし | 必ず `<Link>` でラップ |

---

## アクセシビリティ

- **`<a href>`**: ネイティブ要素を使うので SR / OS 機能 (右クリック新タブ等) がフル機能
- **`disabled`**: `aria-disabled="true"` + `href` 削除でフォーカス移動を防ぐ
- **外部リンク**: `rel="noopener noreferrer"` を自動付与 (タブナビゲーション攻撃の防止)
- **外部アイコン**: `aria-label="外部リンク"` 付きでアイコン化、SR にも伝達
- **フォーカス可視化**: `focus-visible:ring-2` でキーボード操作を明示
- **リンクテキスト**: 「こちら」を避け、遷移先が分かる言葉に (SR の「リンク一覧」機能で意味が取れる)
