## 概要

処理中を示す円形のローディングインジケーター。`role="status"` + `aria-live="polite"` + `.sr-only` テキストを自動装備し、SR ユーザーにも「読み込み中」を伝える。size は xs (12px) から 2xl (64px) まで 6 段階、color は context に合わせて primary / neutral / white の 3 種。

短時間 (1〜2 秒以内) の処理を示す用途。それより長い場合は **Skeleton** や **ProgressBar** で進捗を見せる方が UX 上良い。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| 3 秒以上かかる長い処理を示す | `<Skeleton>` | コンテンツの形を予告して待ち時間体感を短縮 |
| 進捗 % が分かる処理 | `<ProgressBar>` | 推定残り時間と完了を伝えられる |
| 一度きりの状態通知 | `<Toast>` | 「読み込み完了」のような結果通知は Spinner ではなく Toast |
| 永続的なステータス (オンライン / オフライン等) | `<Badge>` | Spinner は「現在処理中」を示す一時的な存在 |

## アクセシビリティ

- **`role="status"`**: SR は live region として認識し、表示されたタイミングで読み上げる
- **`aria-live="polite"`**: 現在の読み上げを中断せず、間が空いたら label を読む (ユーザー操作を妨げない)
- **`aria-label`**: label prop の値が SR ラベルに反映される (デフォルト「読み込み中」)
- **`.sr-only` テキスト**: aria-label に加えて視覚非表示テキストも出力 (一部の SR で aria-label を読まないケースの保険)
- **SVG 自体は `aria-hidden="true"` + `focusable="false"`**: SR 二重読み上げと Tab 移動を防ぐ
- **コントラスト (1.4.11)**: primary / neutral / white すべて適切な背景に対して 3:1 以上を満たす
- **`prefers-reduced-motion`**: 未対応 (AAA 案件、別タスク)

## 関連

### 内部で利用するコンポーネント

なし。Spinner は単独で完結する Primitive (SVG + sr-only span のみ)。

### Spinner を内部で使う代表的なコンポーネント

- `<Button isLoading>` — Button の loading 状態で自動的に内部 Spinner を表示 (size 連動)
- `<SearchBar>` — 検索処理中のインジケーター
- (将来) フォーム送信中の表示など
