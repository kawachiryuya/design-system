## 概要

子要素を垂直方向に等間隔で並べる layout primitive。`gap` で 5 段階 (`xs` 4px / `sm` 8px / `md` 12px / `lg` 16px / `xl` 24px) の**グループ内**間隔を選ぶ。`as` で semantic タグ (`div / section / article / ul / ol / nav / form`) を切替、`align` で cross-axis 配置 (`start / center / end / stretch`) を制御する単機能設計。**page 内の section 分割 (48px+) は Stack ではなく [`<Section>`](?path=/docs/primitives-section--guideline) (`py-section-*`)** を使う。

**実装は `flex flex-col + gap-*`** (`space-y-*` ではない)。Fragment や条件付き children でも余白が崩れない、`gap` 仕様の正攻法。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| 横並び (アイコン + テキスト等) | `<Cluster>` (Phase A 予定) / `flex items-center gap-*` | Stack は垂直専用、horizontal + wrap は Cluster の責務 |
| 1 要素を中央寄せ (max-width 制約) | `<Center>` | Center は単列の水平センタリング、Stack は内部の垂直 spacing 担当 |
| page-level の section 分割 | `<Section>` (`py-section`) | Section が padding を所有しページ構造のリズムを担う。Stack は「グループ内」専用 |
| 2 列以上の grid | `<TwoColumn>` / `<Grid>` | Stack は単列、複数 col は別 composite |

## アクセシビリティ

- **`as` で semantic タグを保つ**: 繰り返し項目なら `as="ul"` (子は `<li>`)、設定 group なら `as="section"`、フォームなら `as="form"`。SR / browser reader-mode / a11y tree の構造が consumer に依存しないように Stack は意味を持たないが、consumer 側で適切な tag を選べる
- **gap と reading order**: gap は視覚的な余白のみ。読み上げ順序は DOM 順そのまま (flex-col による視覚順 = DOM 順なので reorder 問題なし)
- **`align` と LTR/RTL**: `start / end` は CSS logical (flex の `flex-start / flex-end`)、RTL でも自動反転する

## 関連

### 内部で利用するコンポーネント

なし。Stack は単独で完結する Layout primitive。

### Stack を内部で使う代表的なコンポーネント / 使い方

- `<Center>` の中で children を垂直 stacking する時 — Center + Stack の組合せが基本
- form (`as="form"`) — Login / Signup / Settings の field 列
- list (`as="ul"` / `as="ol"`) — sidebar nav / footer link / FAQ accordion list
- 設定画面の group 内 field 列 (`as="form"` + gap="sm")。group 間の section 分割は `<Section>`
- `<Card>` の body 内で複数 paragraph / control を並べる時
