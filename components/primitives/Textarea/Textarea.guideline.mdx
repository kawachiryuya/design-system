## 概要

複数行のテキスト入力を受け付けるフォームコンポーネント。Input と同じ **ラベル / ヘルプテキスト / エラーメッセージの一体管理** + `error` + `errorMessage` の discriminated union による型レベル必須化 を踏襲しつつ、Textarea 固有の **文字数カウンター** (maxLength + currentLength) と **リサイズ挙動** (none/vertical/horizontal/both) を追加で持つ。

長文入力 (コメント・要望・記事本文等) で使う。1 行で十分な場合は **Input** を選ぶ。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| 1 行のテキスト入力 | `<Input>` | 改行不要な短い入力は Input |
| リッチテキスト編集 (太字・リンク等) | (将来) `<RichTextEditor>` | プレーンテキスト以上の編集は別パターン |
| Markdown プレビュー付き | (将来) `<MarkdownEditor>` | Textarea + プレビューパネルの組合せは別 UI |
| コードエディタ | Monaco / CodeMirror 等の外部ライブラリ | シンタックスハイライト等はデザインシステムの範疇外 |

## アクセシビリティ

- **`<label htmlFor>` 自動連携**: `label` prop 指定で自動。クリックでフォーカス、SR がラベルを読む
- **`aria-required`**: `required` 時に自動付与
- **`aria-invalid`**: `error: true` 時に自動付与
- **`aria-describedby`**: `errorMessage` または `helpText` の id と自動関連付け
- **`role="alert"`** (FormMessage 内部): エラーメッセージ表示時に SR が即時通知
- **キーボード**: `Tab` でフォーカス、`Shift+Enter` / `Enter` で改行 (Enter は送信に取られない)
- **文字数カウンター**: 視覚的に表示。上限超過で赤+太字 + SR には errorMessage で明示通知
- **placeholder 色**: `text-onSurface-muted` (#737373) で AA 4.69:1 を満たす

## 関連

### 内部で利用するコンポーネント

- `<Label>` — ラベル描画 + required `*` マーク + disabled 連動 (Input と共通)
- `<FormMessage>` (内部 `_internal/`) — helpText / errorMessage の表示と aria 関連付けを統括

### Textarea と組合せて使う代表的なコンポーネント

- `<Input>` — 同じフォーム内の単行入力 (氏名・メール等)
- `<Button>` — フォーム送信ボタン
- `<Checkbox>` — 同意事項などのフラグ
