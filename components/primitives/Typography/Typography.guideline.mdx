## 概要

タイポグラフィヒエラルキーを実装したテキストコンポーネント。**設計の核** は `variant` (視覚スタイル) と `as` (HTML 意味論) の分離。`variant="h2" as="h3"` のように「見た目は大きいが文書構造上は小さい」を表現できる polymorphic 設計で、文書アウトラインとビジュアル階層を独立に扱える。

`variant` は font-size + line-height + デフォルト font-weight を 1 トークンに集約しているため、`text-heading-xl` のような semantic typography token に対応する。weight は `variant` のデフォルトを `weight` prop で後勝ち上書きできる。

### 別コンポーネントの方が適切な場面

「これは Typography じゃないかも?」と迷ったときは下の表で目的に合うコンポーネントを探す:

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| 押せるテキスト (URL 遷移) | `<Link>` | 文字色だけでなく `<a href>` を出す責務 |
| ステータス / カテゴリ表示 | `<Badge>` | 「短いラベル + バッジ装飾」専用 UI |
| フォーム入力のラベル | `<Label>` | `htmlFor` で input と紐づけ、`*` 必須記号も自動 |
| アイコンとセットで意味を伝える | `<Icon>` + Typography の組合せ | Icon は単独で、テキスト装飾は Typography で |

## アクセシビリティ

- **見出しの階層**: `as` で文書構造の `<h1>` 〜 `<h6>` を正しく出す。SR のヘディングジャンプ (`H` キー等) が機能する
- **`variant` と `as` の分離**: 見た目だけ変えたいときは `variant` だけ変える。例: 「h2 サイズで `<p>`」は `variant="h2" as="p"`
- **色のみの意味伝達禁止**: WCAG 1.4.1 (Use of Color) — 色を意味の唯一の伝達手段にしない。文言と組合せる
- **可読性 (1.4.4 / 1.4.12)**: 本文は body (16px) 以上で書く。拡大 200% 時にも崩れない。`line-height` は variant で適切に設定済
- **コントラスト (1.4.3)**: `color` の各 variant は背景 (`#ffffff`) 比 4.5:1 (大文字は 3:1) を満たすトークンを使用 (primary は darker な `#006f50` で 6.19:1)

## 関連

### 内部で利用するコンポーネント

なし。Typography は単独で完結する Primitive。

### Typography を内部で使う / 組み合わせる代表的なコンポーネント

- `<Link>` — 本文中のリンクは Typography の流れの中で Link が文字色・下線を制御
- `<Label>` — フォームラベルは内部で Typography variant=label を使用
- `<Card>` / `<Alert>` / `<Modal>` — 見出し・本文・キャプションは Typography variant の組合せで構成
