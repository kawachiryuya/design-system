## 概要

**視覚的には非表示だが、DOM とアクセシビリティツリーには残るテキスト** を描画する。Tailwind の `sr-only` ユーティリティを用いる。a11y 補助の基盤コンポーネントとして、icon-only Button の補助ラベル / フォームラベルの省略 / aria-live 通知エリア / Modal close button の代替テキストなどで多用される。

`as` で `span` / `div` / `p` / `label` のタグを切替可能。`as="label"` の場合は `htmlFor` で input と結べる。

### 別コンポーネントの方が適切な場面

| やろうとすること | 使うべき別コンポーネント | 理由 |
|---|---|---|
| icon-only Button | `<Button iconOnly icon={...} aria-label="...">` | Button の専用 API で型レベルに aria-label を必須化 |
| 視覚的にも見せたいが目立たせない | `<Typography color="muted">` | SR から消す必要がなければ通常の text |
| 完全に DOM から消す | `display: none` / `hidden` 属性 | アクセシビリティツリーからも消したいなら専用 CSS |
| Tooltip 風の追加説明 | (将来) `<Tooltip>` / `aria-describedby` | 補助情報を視覚的にも表示するなら Tooltip |

## アクセシビリティ

- **`sr-only` クラス**: 視覚的には完全非表示 (1px サイズ + overflow:hidden + clip-path) だが、DOM とアクセシビリティツリーには残る
- **`display: none` との違い**: display:none は両方から消えるため SR にも読まれない。VisuallyHidden は SR にだけ届く
- **`hidden` 属性との違い**: hidden 属性も両方から消す。同様に VisuallyHidden が正解
- **`as="label"` + `htmlFor`**: フォーム入力欄と紐づける場合に使う。視覚的には placeholder で代替する場面で有効
- **`role="status"` + `aria-live="polite"`**: 動的通知に使う。VisuallyHidden は live region の親コンテナとして好相性
- **冗長付与を避ける**: 既に SR にも読まれる情報がある箇所には VisuallyHidden を足さない

## 関連

### 内部で利用するコンポーネント

なし。VisuallyHidden は単独で完結する Primitive (Tailwind `sr-only` 1 クラスのみ)。

### VisuallyHidden を内部で使う代表的なコンポーネント

- `<Spinner>` の `.sr-only` 補助テキスト (Spinner 内部実装で同等パターン)
- `<Label>` の `*` (必須) マーク補助
- (将来) Toast / Notification 系の aria-live announce
