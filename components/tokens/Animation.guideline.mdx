# Animation

## 概要

トランジション / アニメーションを定義する **2 つの軸**:

- **duration** (動きの長さ) = 開始から終了までの時間
  - `duration-fast` (100ms) / `duration-normal` (200ms) / `duration-slow` (300ms) / `duration-slower` (500ms)
- **easing** (動きのカーブ) = その時間内での加減速のパターン
  - `ease-out` (減速) / `ease-in-out` (両端緩急) / `ease-linear` (一定) / `ease-in` (加速)

**両方を組み合わせて使う**。例: `duration-normal ease-out` = 「200ms で減速しながら動く」。Tailwind の `transitionDuration` / `transitionTimingFunction` に統合済み。

```tsx
<button className="transition-colors duration-normal ease-out">…</button>
```

## 設計方針

- **意味の伝わるラベル**: ms 数値直書きより `fast / normal / slow` の役割名で
- **`normal` (200ms) を default**: 大半の UI トランジション (hover / focus / open) の標準速度
- **`fast` (100ms) は微細な反応 / `slower` (500ms) は強調されたモーション**
- **easing は最小 4 種**: `out` (減速、大半の UI 用)、`in-out` (両端緩急、modal open 等)、`linear` (ローディング等)、`in` (退出)
- **`prefers-reduced-motion` を尊重 (WCAG 2.3.3)**: OS の「視差効果を減らす」設定時は、`tokens/preset.cjs` の base layer で animation / transition をほぼ無効化 (`0.01ms`) する。preset 経由なので Storybook と consumer 双方に自動適用され、個別コンポーネントで `motion-reduce:` を書く必要はない
