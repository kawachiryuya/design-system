# Animation

## 概要

トランジション / アニメーションの **duration** (時間) と **easing** (緩急) の token。Tailwind の `transitionDuration` / `transitionTimingFunction` に統合済み。

利用 utility:
- `duration-{key}` — `duration-fast` / `duration-normal` / `duration-slow` / `duration-slower`
- `ease-{key}` — `ease-out` / `ease-in-out` / `ease-linear` / `ease-in`

例: `<button className="transition-colors duration-normal ease-out">…</button>`

---

## 設計方針

- **意味の伝わるラベル**: ms 数値直書きより `fast / normal / slow` の役割名で
- **`normal` (200ms) を default**: 大半の UI トランジション (hover / focus / open) の標準速度
- **`fast` (100ms) は微細な反応 / `slower` (500ms) は強調されたモーション**: 速さに応じた意味付け
- **easing は最小 4 種**: `out` (減速、大半の UI 用)、`in-out` (両端緩急、modal open 等)、`linear` (ローディング等)、`in` (退出)
