# Color (Primitive)

## 概要

OKLCH ベースで知覚明度を統一したカラーパレット。**Primitive 層は hue 名のみ** (`teal` / `green` / `red` / `orange` / `blue` / `neutral` 等) で構成し、`primary` / `success` / `error` 等の **役割名は [Semantic 層](?path=/docs/tokens-color-semantic--guideline) でのみ** 定義する (2 層アーキテクチャの純度を保つ設計)。

各 palette は 10 段 (`50` / `100` / ... / `900`) のスケールで、`bg-{palette}-{shade}` / `text-{palette}-{shade}` / `border-{palette}-{shade}` の utility で参照可能。

**禁則**: 実装では `bg-teal-700` のような primitive 直参照は **禁止**。必ず [Semantic 層](?path=/docs/tokens-color-semantic--guideline) (`bg-surface-primary` 等) を経由する。理由: 下流 product が brand palette を override したときに自動連動させるため。

---

## 設計方針

- **Primitive は hue 名のみ**: `primary` のような role 名は持たない。Semantic 層 (`surface.primary` 等) で初めて役割を当てる
- **OKLCH ベース**: 知覚明度を palette 間で揃える。同じ shade 番号なら異なる palette でも体感の明度が近い (50: L=0.97 → 900: L=0.31)
- **shade 数値スケール (50〜900)**: Tailwind / Material 慣習に準拠
- **`teal.25` は `bg.default` 専用の例外 shade**: ページ最下層に brand canvas を敷くために追加 ([AGENTS.md §3-3](https://github.com/kawachiryuya/design-system/blob/main/AGENTS.md#3-トークン参照ルール))
- **13 hue + base**: teal / neutral / green / red / orange / blue (semantic で参照される 6 hue) + yellow / lime / cyan / sky / violet / purple / pink (下流用予備 7 hue) + base (white / black / transparent)

---

## カタログ

White / Black から各 hue palette まで全 13 palette + 2 base 色を横ストリップで一覧できます。同 shade を縦に揃えて palette 間の明度・彩度を比較するのに便利。

→ [Tokens/Color/Primitive/Catalog](?path=/story/tokens-color-primitive--catalog) で確認

---

## 下流 product での palette override

Extra palette を brand 色として採用する例:

```js
// tailwind.config.js
module.exports = {
  presets: [require('design-system/tokens/preset.cjs')],
  // Extra palette を semantic 上書きに使う
  theme: {
    extend: {
      backgroundColor: { brand: 'var(--color-violet-600)' },
    },
  },
};
```
