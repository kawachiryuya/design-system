# Focus Ring

## 概要

キーボードで操作する人が「今どこにいるか」を見つけるための輪。形は 3 つの utility (`focus-ring` / `focus-ring-inset` / `focus-ring-on-fill`) で、部品はどれか 1 つを書くだけ。輪が出る条件 (`:focus-visible`) は utility の中に入っている。太さとすき間は CSS 変数 (`--focus-ring-width` / `--focus-ring-offset`)、色は `border.focus` で、下流 product は CSS 変数の上書きで一括変更できる。

```html
<button class="focus-ring">…</button>          <!-- 外側 (既定) -->
<button class="focus-ring-inset">…</button>    <!-- 内側 -->
<button class="focus-ring-on-fill">…</button>  <!-- 濃い塗りの内側 -->
```

## 設計方針

- **どの部品にどの形かの正本は AGENTS.md §3-2「フォーカスの規則」** (DDR-2、#131)。ここには写さない
- **形は名前で選ぶ**: 部品に数値 (`ring-2` / `outline-offset-2` 等) や出る条件 (`focus-visible:`) を書かせない。lint が `focus-ring*` 以外のフォーカスの指定を弾く (AGENTS §3-7)
- **outline で描く**: すき間を塗らない (下の面の色が見える)。ホバーの box-shadow と別の層になる。Windows のハイコントラスト (forced-colors) でも消えない
- **太さは 2px**: WCAG 2.4.13 (Focus Appearance、AAA) 相当を目安にする (準拠は名乗らない)。AA の 2.4.7 (見える) と 1.4.11 (3:1) は必ず満たす (`check:contrast` が `border.focus` × 各下地を検査)
- **primitive 層を持たない**: 値が 2 つしかなく palette 化に意味がないため。詳細は [AGENTS.md §3-4](https://github.com/kawachiryuya/design-system/blob/main/AGENTS.md#3-4-semantic-only-スケール-z-index--opacity--focus-ring)
