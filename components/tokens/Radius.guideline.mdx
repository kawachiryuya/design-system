# Radius

## 概要

角丸 (border-radius) の 5 段スケール。中核は `sm / md / lg` の 3 段、境界値 (`none` / `full`) で角を立てる / 完全な円形を作る。`md` がカノニカルなデフォルトで、bare 形の `rounded` も `rounded-md` (8px) に解決される。

利用 utility: `rounded-{key}` (`rounded-sm` / `rounded-md` / `rounded-lg` / `rounded-none` / `rounded-full`)。

## 設計方針

- **中核 sm/md/lg の 3 段に揃える**: shadow / Button size 等の他カテゴリと統一感を持たせ、選択肢を絞ってデザイン判断を容易に
- **`md` を default に**: `tokens/preset.cjs` で `borderRadius` に `DEFAULT: md` エイリアスを付与し、`rounded` と書けば `md` に解決
- **xs / xl は持たない**: 実利用が薄く、`md = default` の見え方を歪めるため
- **`full` は円形要素 (Avatar / Spinner) 用の特殊値**: 数値スケールではなく semantic 的な役割

詳細: [AGENTS.md §3 サイズスケール内の `md = default` 規約](https://github.com/kawachiryuya/design-system/blob/main/AGENTS.md#サイズスケール内の-md--default-規約)
