# Color (Semantic)

## 概要

実装ではこの semantic 層の token (`bg-surface-*` / `text-onSurface-*` / `border-border-*` / `bg-state-*`) を使う。Primitive (`teal.700` 等) を直接書かないことで、下流 product が brand 色を変えても自動連動する。

5 つのカテゴリ:

| カテゴリ | 用途 | utility 例 |
|---|---|---|
| **bg** | ページ最下層の背景 | `bg-background` |
| **surface** | カード / モーダル / 役割色の塗り | `bg-surface` / `bg-surface-success` |
| **onSurface** | surface 上に載せるテキスト色 | `text-onSurface` / `text-onSurface-subtle` |
| **border** | ボーダー色 | `border-border` / `border-border-subtle` |
| **state** | hover / active のオーバーレイ | `bg-state-hover` / `bg-state-hover-primary` |

## 迷ったらこれ

| やりたいこと | 使う token |
|---|---|
| 普通のカードの背景 | `bg-surface` |
| カードの中に入れ子の区画 | `bg-surface-subtle` |
| Modal の背景マスク | `bg-surface-overlay` |
| Primary Button | `bg-surface-primary` + `text-onSurface-inverse` |
| 通常テキスト | `text-onSurface` |
| 補助テキスト (placeholder / caption) | `text-onSurface-subtle` |
| 区切り線 | `border-border-subtle` |
| Alert 成功 (落ち着いた領域) | `bg-surface-success-muted` + `text-onSurface-success` + `border-border-success-muted` |
| Badge 成功 solid (主張) | `bg-surface-success` + `text-onSurface-inverse` |
| Badge 成功 outline | `border-border-success-strong` + `text-onSurface-success` |
| 白地の押せるもののホバー (Button secondary / Link / Tabs / Card / メニュー項目 等) | `bg-state-hover-primary` (brand 8%) |
| エラー系のホバー | `bg-state-hover-error` |
| 濃い塗り・役割色の面のホバー (Primary Button / 選択中 / Alert の閉じる) | `bg-state-hover` (黒 8%) |
| brand の枠線 (Button secondary / Badge outline) | `border-border-primary-strong` (塗りと同じ 600) |
| 中性の薄い面 (Badge soft neutral) | `bg-surface-neutral-muted` (disabled を借りない) |
| 状態を示す中性の塗り (Switch off / offline dot) | `bg-surface-neutral` (白地に 3:1 以上) |

機能色 (success / error / warning / info) の組合わせ方は [Container Pairs](?path=/story/tokens-color-semantic--container-pairs) story を参照。
