# Color (Semantic)

## 概要

**実装では必ずこの semantic 層を使う**。Primitive palette (`primary.700` 等) を「役割名」で参照することで、下流 product が brand 色を override したときに自動連動する設計。

5 つのカテゴリ:

| カテゴリ | 役割 | 利用 utility |
|---|---|---|
| **bg** | ページ最下層の canvas | `bg-background` |
| **surface** | カード / モーダル / 状態色の塗り (`layer-1/2/3` は depth 階層、`inset` / `overlay` は特殊役割、`primary` / `success` 等は役割色) | `bg-surface-{key}` (DEFAULT = layer-1) |
| **on** | テキスト色 (surface 上に重ねる) | `text-onSurface[-{key}]` |
| **border** | ボーダー色 | `border-border[-{key}]` |
| **state** | hover / active のオーバーレイ (rgba) | `bg-state-{key}` |

各 token は [`tokens/source/semantic-colors.json`](https://github.com/kawachiryuya/design-system/blob/main/tokens/source/semantic-colors.json) で `{ value: "{color.X.Y}", type, description }` の形で定義され、`value` で primitive を参照。

---

## 設計方針

- **value は必ず primitive 参照、生 hex は禁止**: 下流 override に連動するため (詳細 [AGENTS.md §3-1](https://github.com/kawachiryuya/design-system/blob/main/AGENTS.md#3-トークン参照ルール))
- **state は `color-mix()` で primitive と連動**: 透過オーバーレイも primitive 変更に自動追従 ([§3-2](https://github.com/kawachiryuya/design-system/blob/main/AGENTS.md#3-トークン参照ルール))
- **`bg.default` は brand から独立した中性 canvas**: `neutral.50` を参照。下流 product が brand 色を override しても bg は中性のまま ([§3-3](https://github.com/kawachiryuya/design-system/blob/main/AGENTS.md#3-トークン参照ルール))
