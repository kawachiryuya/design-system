# Color (Semantic)

## 概要

実装ではこの semantic 層の token (`bg-surface-*` / `text-onSurface-*` / `border-border-*` / `bg-state-*`) を使う。Primitive (`teal.700` 等) を直接書かないことで、下流 product が brand 色を変えても自動連動する。

5 つのカテゴリ:

| カテゴリ | 用途 | utility 例 |
|---|---|---|
| **bg** | ページ最下層の背景 | `bg-background` |
| **surface** | カード / モーダル / 役割色の塗り | `bg-surface` / `bg-surface-success` |
| **on** | surface 上に載せるテキスト色 | `text-onSurface` / `text-onSurface-muted` |
| **border** | ボーダー色 | `border-border` / `border-border-subtle` |
| **state** | hover / active のオーバーレイ | `bg-state-hover` / `bg-state-hover-primary` |

## 迷ったらこれ

| やりたいこと | 使う token |
|---|---|
| 普通のカードの背景 | `bg-surface` |
| カードの中に入れ子のセクション | `bg-surface-layer-2` |
| 入力フィールドの背景 (凹み) | `bg-surface-inset` |
| Modal の背景マスク | `bg-surface-overlay` |
| Primary Button | `bg-surface-primary` + `text-onSurface-inverse` |
| 通常テキスト | `text-onSurface` |
| 補助テキスト (placeholder / caption) | `text-onSurface-muted` |
| 区切り線 | `border-border-subtle` |
| Alert 成功 (落ち着いた領域) | `bg-surface-success-muted` + `text-onSurface-success` + `border-border-success-subtle` |
| Badge 成功 solid (主張) | `bg-surface-success` + `text-onSurface-inverse` |
| Badge 成功 outline | `border-border-success-emphasis` + `text-onSurface-success` |
| 色付き背景上の hover | `bg-state-hover` |
| 白系背景上の brand hover | `bg-state-hover-primary` |

機能色 (success / error / warning / info) の組合わせ方は [Container Pairs](?path=/story/tokens-color-semantic--container-pairs) story を参照。
