# Typography (Semantic)

## 概要

タイポグラフィの semantic 層。`heading.{display,xl,lg,md,sm}` / `body.{lg,md,sm}` / `label` / `caption` の 10 種類を「役割名」で参照する。Typography コンポーネントの `variant` prop と 1:1 対応。

利用 utility:
- `text-heading-{display,xl,lg,md,sm}` — 見出し
- `text-body-{lg,md,sm}` — 本文
- `text-label` — フォームラベル
- `text-caption` — 注釈

各 token は font-size + (任意の) font-weight + line-height + letter-spacing をセットで保持し、Tailwind の `fontSize` extend で 1 utility class として生成される。

## カタログ

→ [Tokens/Typography/Semantic/Catalog](?path=/story/tokens-typography-semantic--catalog) で確認

heading (5 段) → body (3 段) → label → caption の順で全 10 token を大→小の順に並列表示。

---

## 設計方針

- **役割名で意図を表現**: `text-2xl` ではなく `text-heading-md` と書くことで「これは見出し」が明確
- **font-weight を含まない utility**: Typography variant の weight 上書きを `font-{weight}` で効かせるため、font-size utility には weight を注入しない (preset.cjs の `flattenSemanticTypo` で意図的に省略)
- **heading は 5 段、body は 3 段**: 大半の UI に必要十分
