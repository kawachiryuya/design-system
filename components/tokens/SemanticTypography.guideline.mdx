# Typography (Semantic)

## 概要

タイポグラフィの semantic 層 = **text style**。`heading.{display,xl,lg,md,sm}` / `body.{lg,md,sm}` / `control.{sm,md,lg}` / `label` / `caption` の 13 種類を「役割名」で参照する。各 style は size + line-height + weight (+ 字間) をセットで持つ 1 クラス `type-{role}`。heading / body / label / caption は Typography コンポーネントの `variant` prop と 1:1 対応、control は Button / Link 等の size 段。

利用 utility:
- `type-heading-{display,xl,lg,md,sm}` — 見出し
- `type-body-{lg,md,sm}` — 本文 (Input / Select / Link の文字もここ)
- `type-control-{sm,md,lg}` — 操作部品のラベル (Button / SegmentedControl / Pagination / ToggleButton)。medium、行間 tight
- `type-label` — フォームラベル
- `type-caption` — 注釈

各 token は font-size + font-weight + line-height (+ letter-spacing) をセットで保持し、preset が components 層の `.type-{role}` クラスとして生成する。weight だけを変えたいときは `type-heading-md font-normal` のように `font-{weight}` を重ねる (utilities 層が後勝ち)。**出荷コンポーネントで primitive の `text-{size}` / `leading-*` / `tracking-*` を直接書くのは lint で禁止** (AGENTS §3-7)。

## 設計方針

- **役割名で意図を表現**: `text-2xl` ではなく `type-heading-md` と書くことで「これは見出し」が明確
- **weight まで含む text style**: 1 クラスで文字の見え方が決まる (size だけの utility だと weight / 行間を部品ごとに手で書くことになり、primitive 直参照が増える)。上書きは `font-{weight}` のみ
- **control は body と別**: 操作部品のラベルは medium + 行間 tight (1.25)、本文は regular + 1.5。同じ 14 / 16 / 18px でも役割が違う
- **body-sm (14px) は UI 文言用**: ラベル・補助・表の中など。記事や長文の本文は body-md (16px) 以上 (Readability 原則)
- **heading は 5 段、body は 3 段**: 大半の UI に必要十分
- **見出しは和文最適化**: display/xl/lg は letter-spacing 0 (欧文のネガティブ字間は漢字連続で窮屈になるため) + line-height snug (1.35)。さらに詰めたい場合は字形側の `font-feature-settings: "palt"` を推奨
