# Typography (Primitive)

## 概要

タイポグラフィの primitive 層。font-size / weight / line-height / letter-spacing / family の 5 軸を持つ。`text-{key}` / `font-{key}` / `leading-{key}` / `tracking-{key}` / `font-{family}` の utility で参照。

**禁則**: コンポーネント実装では原則 [Semantic 層](?path=/docs/tokens-typography-semantic--guideline) (`text-heading-xl` / `text-body-md` 等) を使う。primitive (`text-2xl` 等) 直接利用は限定的に。

---

## カタログ

- [FontSizes](?path=/story/tokens-typography-primitive--font-sizes) — xs〜5xl の 9 段のフォントサイズ
- [FontWeights](?path=/story/tokens-typography-primitive--font-weights) — regular / medium / semibold / bold の 4 段
- [LineHeights](?path=/story/tokens-typography-primitive--line-heights) — tight / normal / relaxed の 3 段
- [LetterSpacings](?path=/story/tokens-typography-primitive--letter-spacings) — tight / normal / wide の 3 段
- [FontFamilies](?path=/story/tokens-typography-primitive--font-families) — sans / mono の 2 種

---

## 設計方針

- **font-size**: Tailwind 標準スケール (xs〜5xl) を採用、9 段
- **font-weight**: regular / medium / semibold / bold の 4 段。light は orphan として削除済
- **line-height**: tight (1.25) / normal (1.5) / relaxed (1.75) の 3 段。loose は orphan として削除済
- **letter-spacing**: tight (-0.02em) / normal / wide の 3 段
- **font-family**: sans / mono の 2 種。serif は orphan として削除済
