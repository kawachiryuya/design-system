# Toast の作り直し — 検討（Issue #91）

相談の中で Ryuya に見せた絵と案を、採らなかったものも含めてここに積む。決まったら、下書きのまま閉じる。

絵はチャットの中に出したもの（色はチャットの側の変数。design-system の色ではない）。**絵で決めるのは方向だけ。形と色は実物で決める。**

## 01 役目をどこまでにするか（2026-11-27）

`01-role.html` — 同じ「アーカイブ」の場面で 3 つを並べた。

- 今のまま：何でも知らせる（色 5 種類、見出し + 本文 + 操作 + 閉じる）
- A 案「いまの操作の結果を一言で」：1 文 + 操作 1 つまで。「できた」「できなかった」の 2 種類。見出しは無くす（勧め）
- B 案「できたことだけ」：失敗は Toast に出さず、画面の中の Alert・欄のエラーで伝える

決まったこと：**A 案**（Ryuya「A でよさそう」）

## 消え方と閉じる ×（絵は無い。言葉で決めた）

「できた」は自動で消えて × 無し（操作つきは 10 秒）。「できなかった」は消えずに × あり（Ryuya「まずは b がいいな」＝仮決め）

## 02 どこに出すか

`02-position.html` — 狭い幅の FormDialog で 3 つ（今のまま＝下端で「適用」に重なる／A 案＝下でフッターを避ける／B 案＝上）。チャットでは 3 つとも画面の絵で出した。このファイルは 1 つ目だけ画面の絵で、残りは位置の値を書いてある。

決まったこと：**下に出す。下のものは避けずに重ねる**（Ryuya「まずは下部にでるのがいい」「レイヤー的には重なるのが自然なのかも」。勧めていた A 案の「避ける」は採らない。`position` の指定は無くす）

## 03 重なったときの逃げ道

`03-swipe.html` — 下のナビに乗った「元に戻す」つきの Toast を、下へ払うと消せる試作（触れる。24px より下へ動かして離すと消える。触れている間は 10 秒の残りを止める）。

案：今のまま（10 秒待つ）／A 案「下へ払うと消える」（勧め）／B 案「× を全部に戻す」

決まったこと：まだ無い（Ryuya「A でみてみたい」→ 試作を出した。返事待ち）
