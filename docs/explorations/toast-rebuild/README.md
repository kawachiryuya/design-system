# Toast の作り直し — 検討（Issue #91）

相談の中で Ryuya に見せた絵と案を、採らなかったものも含めてここに積む。決まったら、下書きのまま閉じる。

絵はチャットの中に出したもの（色はチャットの側の変数。design-system の色ではない）。**絵で決めるのは方向だけ。形と色は実物で決める。**

## 01 役目をどこまでにするか（2026-11-27）

`01-role.html` — 同じ「アーカイブ」の場面で 3 つを並べた。

- 今のまま：何でも知らせる（色 5 種類、見出し + 本文 + 操作 + 閉じる）
- A 案「いまの操作の結果を一言で」：1 文 + 操作 1 つまで。「できた」「できなかった」の 2 種類。見出しは無くす（勧め）
- B 案「できたことだけ」：失敗は Toast に出さず、画面の中の Alert・欄のエラーで伝える

決まったこと：**A 案**（Ryuya「A でよさそう」）

## 消え方と閉じる ×（絵は無い。言葉で決めた）

「できた」は自動で消えて × 無し（操作つきは 10 秒）。「できなかった」は消えずに × あり（Ryuya「まずは b がいいな」＝仮決め）

## 02 どこに出すか

`02-position.html` — 狭い幅の FormDialog で 3 つ（今のまま＝下端で「適用」に重なる／A 案＝下でフッターを避ける／B 案＝上）。チャットでは 3 つとも画面の絵で出した。このファイルは 1 つ目だけ画面の絵で、残りは位置の値を書いてある。

決まったこと：**下に出す。下のものは避けずに重ねる**（Ryuya「まずは下部にでるのがいい」「レイヤー的には重なるのが自然なのかも」。勧めていた A 案の「避ける」は採らない。`position` の指定は無くす）

## 03 重なったときの逃げ道

`03-swipe.html` — 下のナビに乗った「元に戻す」つきの Toast を、下へ払うと消せる試作（触れる。24px より下へ動かして離すと消える。触れている間は 10 秒の残りを止める）。

案：今のまま（10 秒待つ）／A 案「下へ払うと消える」（勧め）／B 案「× を全部に戻す」

決まったこと：**A 案「下へ払うと消える」**（Ryuya、試作を触って「よさそう」）

## 04 「元に戻す」つきが消えるまでの秒数

Ryuya「10 秒が体感として長いかも」→ `03-swipe.html` に 5 秒・7 秒・10 秒の切り替えを足した（最初の版は 10 秒固定。1 つ前のコミット）。

決まったこと：**7 秒**（Ryuya、触り比べて「7秒良さそう」）

## 05 続けて出たとき、何枚まで見せるか（絵は無い。言葉で決めた）

案：今のまま（5 枚まで積む）／A 案「いつも 1 枚」（新しいものが入れ替える）／B 案「できなかった、は残す」（ふだんは 1 枚で入れ替え。失敗が出ている間はそれを残して新しい 1 枚を上に。最大 2 枚）

決まったこと：**B 案**（Ryuya「b」）

## 06 決めたことからそのまま出るもの（まとめて問い、Ryuya「なし」＝覆すものは無い）

出し方は `useToast()` だけ（`<Toast>` を直接置く形は無くす）／秒数は部品が決める（できた 5 秒・元に戻すつき 7 秒・できなかったは消えない。指定は無くす）／種類は `success`・`error`、本文は `description` → `message`／操作は 1 つ・短い言葉／読み上げは今のまま／Issue #176 を一緒に直す

## 実物で決めること（この PR に、実物の案を積む）

- 形と色（今の「役割色の薄い箱」をやめるか。Alert と見分けがつくこと）。実物で 3 通り
- 文が 2 行以上のときの、アイコン（1 行目に固定が勧め）と操作（右端・上下の真ん中が勧め）の位置。1 行・2 行・長い操作名で並べる
- 広い幅で、下の中央か右下か
- 下のナビ（AppShell）に乗せた形で、払う動きと 7 秒を触る

## 07 実物の案（`app/`）

`app/` — design-system の本物の token・Tailwind の preset・部品（AppShell・Button・Alert・Radio・Icon・Typography）で組んだ、スマホで触れる 1 ページ。Toast だけは、ここまでに決まったことで作った検討用の新しい実装（`app/src/toast/`。出荷する `components/composites/Toast/` は変えていない）。

検討用の Toast に入れたもの（決まったこと）：1 文 + 操作 1 つまで／「できた」「できなかった」の 2 種類・見出し無し／「できた」は 5 秒・操作つき 7 秒で自動で消えて × 無し（触れている・マウスが乗っている・フォーカスがある間は残りを止める）／「できなかった」は消えず × あり／下に出して、下のナビは避けずに重ねる／下へ払うと消える（24px より下で離す。「できなかった」も）／ふだん 1 枚で入れ替え、「できなかった」は残して新しい 1 枚をその上に（最大 2 枚）／`useToast()` の `toast({ variant, message, action })`／読み上げは できなかった＝`role="alert"`・できた＝`role="status"`／動きを減らす設定では出入りの動きを無くす

ページの上の帯（畳める。畳んでも今の組が 1 行で読める。選んだ組は URL の hash に入るので、URL を送れば同じ組で開く）で切り替えるもの：

- 形と色：今のまま（見比べる用。今の Toast の役割色の薄い箱）／A 濃い面／B 白い面＋影／C 役割色で塗った面
- 文が 2 行以上のときのアイコン：1 行目に固定（勧め）／上下の真ん中
- 操作の位置：右端で上下の真ん中（勧め）／文の下の段（右寄せ）
- 広い幅での置き場所：下の中央／右下（狭い幅＝下のナビが出る幅は、どちらも左右に余白を取って下の中央。最大幅は 28rem）

本文の場面のボタン：できた・1 行／できた・2 行／元に戻すつき・1 行／元に戻すつき・2〜3 行／長い操作名＋2 行／できなかった・1 行／できなかった・再試行つき・2 行／できなかった → 続けて できた（2 枚）。見比べる用の本物の Alert（success・error）と、縦にスクロールできるダミーの一覧も置いた。

ビルドのしかた（リポジトリの直下で）：

```sh
npm ci --ignore-scripts
npm run tokens:build
npx vite build -c docs/explorations/toast-rebuild/app/vite.config.ts --outDir <出力先> --emptyOutDir
```

出力は `index.html` と `assets/` だけ（`base: './'`。外への通信は無い）。`--outDir` を省くと `app/dist/`（追跡しない）。型の確認は `npx tsc -p docs/explorations/toast-rebuild/app/tsconfig.json`（リポジトリの `npm run typecheck` の対象には入らない）。
