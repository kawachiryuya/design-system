## 実物で決めること（この PR に、実物の案を積む）

## 07 実物の案（`app/`）

`app/` — design-system の本物の token・Tailwind の preset・部品（AppShell・Button・Alert・Radio・Icon・Typography）で組んだ、スマホで触れる 1 ページ。Toast だけは、ここまでに決まったことで作った検討用の新しい実装（`app/src/toast/`。出荷する `components/composites/Toast/` は変えていない）。

検討用の Toast に入れたもの（決まったこと）：1 文 + 操作 1 つまで／「できた」「できなかった」の 2 種類・見出し無し／「できた」は 5 秒・操作つき 7 秒で自動で消えて × 無し（触れている・マウスが乗っている・フォーカスがある間は残りを止める）／「できなかった」は消えず、閉じるあり／下に出して、下のナビは避けずに重ねる／下へ払うと消える（24px より下で離す。「できなかった」も）／ふだん 1 枚で入れ替え、「できなかった」は残して新しい 1 枚をその上に（最大 2 枚）／`useToast()` の `toast({ variant, message, action })`／読み上げは できなかった＝`role="alert"`・できた＝`role="status"`／動きを減らす設定では出入りの動きを無くす

### 1 回目の切り替え（2026-11-27）

形と色（今のまま／A 濃い面／B 白い面＋影／C 役割色で塗った面）・2 行以上のときのアイコンの位置（1 行目に固定／上下の真ん中）・操作の位置（右端／下の段）・広い幅での置き場所（下の中央／右下）を、帯で切り替えて触った。

決まったこと：**形は A「濃い面」がベース**／**アイコンは 1 行目に固定**／**広い幅は下の中央**（Ryuya、触って絞った。11-27）。この 3 つは切り替えを外して固定した。

### 2 回目の切り替え

ページの上の帯（畳める。畳んでも今の組が 1 行で読める。選んだ組は URL の hash に入るので、URL を送れば同じ組で開く）で切り替えるもの。既定は「A2／閉じる（文字）／1 つなら右端、2 つなら下の段」。

- 「できなかった」の色（できた、はどれも A の濃い面）：A1 濃い面のまま（アイコンの色だけ赤系）／A2 できなかった、は赤い面（`surface.error` に白い文字）／A3 濃い面＋赤い印（アイコンを赤い塗りの丸に白い「!」）
- 閉じるの形：×（アイコンのボタン）／閉じる（文字のボタン。操作と同じ並びで「閉じる」が左・操作が右。操作は太字、閉じるは通常の太さ。読み上げ名は「通知を閉じる」）
- ボタンの位置：右端（文の右、上下の真ん中）／下の段（いつも文の下に右寄せ）／1 つなら右端、2 つなら下の段（× は並びに数えず、いつも右上）

本文の場面のボタン：できた・1 行／できた・2 行／元に戻すつき・1 行／元に戻すつき・2〜3 行／長い操作名＋2 行／できなかった・1 行／できなかった・再試行つき・2 行／できなかった → 続けて できた（2 枚）。見比べる用の本物の Alert（success・error）と、縦にスクロールできるダミーの一覧も置いた。

### 3 回目（2026-11-27 9 時）— 色は A2、ボタンの位置の切り分け

決まったこと（Ryuya）
- 「できなかった」の色は **A2（赤い面）**。「できた」は濃い面のまま
- × は **「閉じる」の文字のボタン**にして、操作と並べる（左に「閉じる」、右端に操作。操作だけ太字）
- ボタンの位置は **「1 行に収まるなら右端」**：ボタン（群）を文の右に置いても文が 1 行に収まるときだけ横に並べる。折り返すなら、ボタンは下の段に右寄せし、文は面の幅いっぱいを使う。ボタンの数・ラベルの長さ・画面の幅を 1 つの決まりで扱う（CSS の flex-wrap で決まる。測らない）

帯に残っている切り替え（見比べ用）：閉じるの形（×／文字）、ボタンの位置（いつも下の段／1 つなら右端・2 つなら下の段／文字数で分ける（Ryuya の案。5 文字以上は下の段）／1 行に収まるなら右端）。場面に「できた・短い文＋長い操作名」「できなかった・短い文＋再試行」を足した。
