# セマンティックカラー

## 原則の定義

**特定の意味や状態を伝える色を定義し、一貫して使用する**

## 主要なセマンティックカラー

### Success（成功）
**意味**: 操作の成功、正常な状態  
**色**: 緑系（green-600）  
**用途**: 成功メッセージ、完了状態、正常インジケーター

### Error（エラー）
**意味**: エラー、失敗、危険  
**色**: 赤系（red-600）  
**用途**: エラーメッセージ、バリデーション、削除警告

### Warning（警告）
**意味**: 注意、警告  
**色**: 黄/橙系（yellow-600, orange-600）  
**用途**: 警告メッセージ、注意喚起

### Info（情報）
**意味**: 情報、ヒント  
**色**: 青系（blue-600）  
**用途**: 情報メッセージ、ツールチップ、ヘルプ

## 色だけに依存しない

**原則**: 色 + アイコン + テキスト

```
✅ 良い例:
[✓ アイコン] 保存しました（緑色）

❌ 悪い例:
保存しました（緑色のみ）
```

→ 詳細は [Color Contrast](?path=/docs/principles-foundation-accessibility--docs)
