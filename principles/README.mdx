## ドキュメントの読み方

### 効率的な学習方法

1. **各カテゴリの overview から読む** — 全体像を把握してから詳細に降りる
2. **必要なトピックだけ読む** — 全部を読む必要はない
3. **関連ドキュメントを辿る** — 各ファイルの末尾に関連リンクがある
4. **チェックリストで確認** — 実装時に活用

### ドキュメントの構成テンプレート

新規に原則 mdx を追加する場合、以下の構成に揃えてください:

```markdown
## メタ情報 (カテゴリ・適用範囲・ステータス・最終更新)
## 原則の定義 (一文で要約)
## なぜ必要か / 背景
## 詳細説明 (✅/❌ の具体例つき)
## チェックリスト
## 関連原則 / 関連コンポーネント
## バージョン履歴
```

実装規約 (props 形式、トークン参照ルール等) は `AGENTS.md` を参照してください。
